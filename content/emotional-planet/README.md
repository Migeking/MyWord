# 情绪星球 - Emotional Planet

一个基于 Three.js 的交互式情绪可视化视频生成器。

## 功能特点

- **流体粒子系统**：8000+ 粒子组成的情绪星球，支持四色情绪表达（金/蓝/红/灰）
- **完整的视频脚本**：60 秒逐秒脚本，15 个分镜场景
- **实时渲染**：基于 WebGL 的实时粒子渲染，支持 60fps 流畅动画
- **录制功能**：内置 Canvas 录制，支持导出 WebM 格式视频
- **纯代码生成**：日历、手机界面、AI 界面等元素全部代码绘制

## 使用方法

1. 在浏览器中打开 `index.html`
2. 点击「播放」按钮观看完整的 60 秒视频
3. 点击「录制」按钮可以录制视频并下载

## 技术栈

- **Three.js** - WebGL 3D 渲染引擎
- **GSAP** - 动画库
- **Simplex Noise** - 流体效果噪声生成
- **MediaRecorder API** - 视频录制

## 自定义

### 修改情绪分布比例

在 `CONFIG.colors` 中修改各情绪的比例：

```javascript
const distribution = {
    joy: 0.25,    // 25% 开心
    sad: 0.20,    // 20% 难过
    angry: 0.15,  // 15% 焦虑
    calm: 0.40    // 40% 平静
};
```

### 修改粒子数量

```javascript
particles: {
    count: 8000,  // 粒子数量（建议 5000-15000）
    size: 0.08,   // 粒子大小
    speed: 0.002  // 运动速度
}
```

### 修改视频时长

```javascript
duration: 60,  // 视频时长（秒）
```
