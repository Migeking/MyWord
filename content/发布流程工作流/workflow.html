Step 2：Playwright 截图

2.1 修改截图脚本 capture_xhs_frames.py

每次使用需修改 3 处：HTML 路径、视口尺寸、总帧数。

"""Capture frames at 10fps from animated HTML."""
import asyncio, os, glob
from playwright.async_api import async_playwright

async def capture():
    # ⚠️ 修改为当前文章的 HTML
    html_path = os.path.abspath("D:/code/MyWord/xhs-output/[文章名]_animated.html")
    slides_dir = os.path.abspath("D:/code/MyWord/xhs-output/slides")
    os.makedirs(slides_dir, exist_ok=True)
    for f in glob.glob(os.path.join(slides_dir, "*.png")): os.remove(f)

    async with async_playwright() as p:
        browser = await p.chromium.launch(
            headless=True,
            args=["--no-sandbox","--disable-setuid-sandbox","--disable-web-security"])
        # ⚠️ 1080×1440 视口（与 HTML 匹配）
        page = await browser.new_page(viewport={"width":1080,"height":1440})
        await page.goto(f"file:///{html_path.replace(chr(92),'/')}")
        await page.wait_for_timeout(4000)  # Wait for fonts+GSAP init

        total_frames = 350  # ⚠️ 35s @ 10fps
        for i in range(total_frames):
            await page.screenshot(
                path=os.path.join(slides_dir,f"frame_{i:04d}.png"))
            if i < total_frames-1: await asyncio.sleep(0.1)
        await browser.close()
    print(f"Done: {len(glob.glob(slides_dir+'/frame_*.png'))} frames")

asyncio.run(capture())

常见问题

Q1: 视频分辨率不够高清？

原因：用了 390×844 旧规范。
解决：必须用 1080×1440（3:4），FFmpeg 也出同等分辨率。

Q2: BGM 下载太慢？

解决：先用 curl -L -r 0-5000000 只下载前 5MB（足够 35s），
或一次下载全部精选曲目后缓存使用。

Q3: publish_pipeline.py 超时？

解决：重启 Chrome → chrome_launcher.py --restart → 重新发布。

Q4: 发布按钮点击无效？

解决：等待视频转码完成后自动显示。耐心等待 10-60s。

Q5: UnicodeEncodeError / 乱码？

解决：文件路径用英文/ASCII；写文件用 UTF-8 编码。

C3：ChatTTS 逐段配音

固定 seed 保持同声线，每 slide 生成独立 WAV 文件。
重要：每次 chat.infer() 前必须 torch.manual_seed(SEED)，不得批量传参。 

import torch, ChatTTS, soundfile as sf
chat = ChatTTS.Chat(); chat.load(compile=False)
SEED = 42
for i, text in enumerate(slides):
    torch.manual_seed(SEED)
    wavs = chat.infer([text], use_decoder=True)
    sf.write(f"assets/chattts-slide-{i+1}.wav", wavs[0], 24000)
