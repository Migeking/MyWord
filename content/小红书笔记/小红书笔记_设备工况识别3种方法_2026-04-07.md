### 一、为什么工况识别这么重要？

**动态阈值的核心逻辑：**

```
不同工况 → 振动基线不同 → 阈值应该不同

举例：
某风机空载时振动 = 0.6-0.9 mm/s（正常）
某风机满载时振动 = 0.4-0.7 mm/s（正常）

如果不知道工况：
├── 用固定阈值0.8 → 空载天天误报
└── 用固定阈值0.7 → 满载时漏报

如果知道工况：
├── 空载时阈值用1.2（基线0.75×1.5）
└── 满载时阈值用0.9（基线0.55×1.5）
```

**工况识别的3种方法：**

| 方法 | 难度 | 成本 | 准确率 | 适用场景 |
|------|------|------|--------|----------|
| 方法1：读取设备负载信号 | 低 | 无 | 99% | 新设备、有PLC |
| 方法2：用电流估算负载 | 中 | 低 | 85-90% | 大部分设备 |
| 方法3：振动数据聚类 | 高 | 无 | 80-90% | 老设备、无信号 |

### 二、方法1：读取设备负载信号（最准）

**原理：**
直接从设备控制系统读取负载信号。

**信号来源：**

| 设备类型 | 负载信号 | 信号类型 |
|----------|----------|----------|
| 泵/风机 | 流量、压力 | 4-20mA模拟量 |
| 压缩机 | 排气压力、流量 | 4-20mA |
| 机床 | 主轴负载率 | PLC内部变量 |
| 输送带 | 皮带秤称重 | 4-20mA/数字量 |
| 搅拌机 | 扭矩 | 4-20mA |

**实现方式：**

**方式A：硬接线采集**
```
负载传感器（4-20mA）
    → DAQ采集卡
    → 边缘网关
    → 预警系统
```

**方式B：PLC通讯**
```
设备PLC（Modbus/OPC UA）
    → 边缘网关（读取内部变量）
    → 预警系统
```

**代码示例（Python读取Modbus）：**

```python
from pymodbus.client import ModbusTcpClient

# 连接PLC
client = ModbusTcpClient('192.168.1.100', port=502)
client.connect()

# 读取负载率（假设在寄存器地址40001）
result = client.read_holding_registers(0, 1, unit=1)
load_rate = result.registers[0] / 100.0  # 转成百分比

print(f"当前负载率：{load_rate}%")

# 判断工况
if load_rate < 20:
    status = "空载"
elif load_rate < 80:
    status = "半载"
else:
    status = "满载"

print(f"工况：{status}")
```

**优点：**
- 准确率最高（99%+）
- 实时性好
- 不增加额外成本（如果设备本来就有）

**缺点：**
- 老设备可能没有负载信号
- 需要接入PLC，涉及设备方配合
- 有时设备方不愿开放PLC接口

**适用场景：**
- 新设备（有完善的控制系统）
- 设备方愿意配合
- 有自动化工程师支持

### 三、方法2：用电流估算负载（最实用）

**原理：**
电机电流和负载成正比。

```
电机负载率 ≈ 当前电流 / 额定电流

举例：
额定电流 = 100A
当前电流 = 60A
负载率 ≈ 60%
```

**为什么这个方法好用：**
- 电流传感器便宜（霍尔传感器30-50元）
- 安装简单（夹在电源线上）
- 不需要接入设备PLC
- 电机都有电流，通用性强

**硬件实现：**

```
电机电源线
    → 霍尔电流传感器（输出0-5V）
    → DAQ采集卡
    → 边缘网关
    → 预警系统
```

**代码示例：**

```python
import numpy as np

class LoadEstimator:
    def __init__(self, rated_current):
        """初始化
        Args:
            rated_current: 额定电流（A）
        """
        self.rated_current = rated_current
        self.current_history = []
    
    def estimate_load(self, current):
        """估算负载率
        Args:
            current: 当前电流（A）
        Returns:
            load_rate: 负载率（0-100%）
        """
        # 平滑处理（取过去10次平均值）
        self.current_history.append(current)
        if len(self.current_history) > 10:
            self.current_history.pop(0)
        
        avg_current = np.mean(self.current_history)
        
        # 计算负载率
        load_rate = (avg_current / self.rated_current) * 100
        load_rate = max(0, min(100, load_rate))  # 限制在0-100
        
        return load_rate
    
    def get_status(self, load_rate):
        """判断工况
        Args:
            load_rate: 负载率（%）
        Returns:
            status: 工况名称
        """
        if load_rate < 20:
            return "空载"
        elif load_rate < 50:
            return "轻载"
        elif load_rate < 80:
            return "半载"
        else:
            return "满载"


# 使用示例
estimator = LoadEstimator(rated_current=100)  # 额定电流100A

# 模拟电流采集（实际从传感器读取）
current = 65  # 当前电流65A

load_rate = estimator.estimate_load(current)
status = estimator.get_status(load_rate)

print(f"电流：{current}A")
print(f"负载率：{load_rate:.1f}%")
print(f"工况：{status}")
```

**注意事项：**

1. **启动电流问题**
   - 电机启动瞬间电流是额定电流的5-7倍
   - 需要过滤启动过程（前30秒不判断）

2. **空载电流问题**
   - 电机空载时电流不是0，大约是额定电流的20-30%
   - 计算负载率时要减去空载电流：
   ```python
   # 改进的负载率计算
   no_load_current = rated_current * 0.25  # 空载电流
   load_rate = (current - no_load_current) / (rated_current - no_load_current) * 100
   ```

3. **不同设备类型差异**
   ```
   风机/泵类：电流和负载基本线性
   输送带：电流和负载基本线性
   压缩机：有周期性波动，需要平滑
   破碎机：负载变化剧烈，需要长时间窗口
   ```

**优点：**
- 成本低（30-50元/个）
- 安装简单
- 准确率较高（85-90%）
- 不需要设备方配合

**缺点：**
- 需要额外安装电流传感器
- 启动过程要过滤
- 不同设备类型要调整参数

**适用场景：**
- 大部分设备（电机驱动）
- 设备方不愿开放PLC接口
- 预算有限

### 四、方法3：振动数据聚类（最省钱）

**原理：**
设备不同工况时，振动特性不同，用聚类算法自动分组。

```
假设某风机：
├── 空载时振动RMS = 0.6-0.9，主频峰值在50Hz
├── 半载时振动RMS = 0.5-0.7，主频峰值在48Hz
└── 满载时振动RMS = 0.4-0.6，主频峰值在45Hz

聚类算法会自动发现：
├── 第1类（空载）：RMS高，频率高
├── 第2类（半载）：RMS中，频率中
└── 第3类（满载）：RMS低，频率低
```

**为什么可行？**
- 空载和满载时，设备转速、负载都不同
- 这些差异会反映在振动数据上
- 用算法自动发现这些模式

**算法选择：K-means聚类**

```python
import numpy as np
from sklearn.cluster import KMeans
from sklearn.preprocessing import StandardScaler

class OperatingConditionCluster:
    def __init__(self, n_clusters=3):
        """初始化
        Args:
            n_clusters: 聚类数量（通常3类：空载/半载/满载）
        """
        self.n_clusters = n_clusters
        self.kmeans = None
        self.scaler = StandardScaler()
        self.is_trained = False
        
    def extract_features(self, vibration_data, sample_rate=10000):
        """从振动数据提取特征
        Args:
            vibration_data: 振动时域数据（numpy数组）
            sample_rate: 采样率（Hz）
        Returns:
            features: 特征向量 [RMS, Peak, Kurtosis, 主频幅值]
        """
        # 时域特征
        rms = np.sqrt(np.mean(vibration_data**2))
        peak = np.max(np.abs(vibration_data))
        kurtosis = np.mean((vibration_data - np.mean(vibration_data))**4) / (np.var(vibration_data)**2)
        
        # 频域特征（FFT）
        fft_result = np.fft.fft(vibration_data)
        fft_magnitude = np.abs(fft_result[:len(fft_result)//2])
        freqs = np.fft.fftfreq(len(vibration_data), 1/sample_rate)[:len(fft_result)//2]
        
        # 找主频（幅值最大的频率）
        main_freq_idx = np.argmax(fft_magnitude)
        main_freq_amplitude = fft_magnitude[main_freq_idx]
        
        return np.array([rms, peak, kurtosis, main_freq_amplitude])
    
    def train(self, vibration_data_list):
        """训练聚类模型
        Args:
            vibration_data_list: 历史振动数据列表（每条是一个时间段的数据）
        """
        # 提取特征
        features_list = []
        for data in vibration_data_list:
            features = self.extract_features(data)
            features_list.append(features)
        
        X = np.array(features_list)
        
        # 标准化
        X_scaled = self.scaler.fit_transform(X)
        
        # 训练K-means
        self.kmeans = KMeans(n_clusters=self.n_clusters, random_state=42)
        self.kmeans.fit(X_scaled)
        
        self.is_trained = True
        
        return self.kmeans.labels_
    
    def predict(self, vibration_data):
        """预测当前工况
        Args:
            vibration_data: 当前振动数据
        Returns:
            cluster_label: 聚类标签（0, 1, 2...）
        """
        if not self.is_trained:
            raise Exception("模型未训练，请先调用train方法")
        
        # 提取特征
        features = self.extract_features(vibration_data)
        features = features.reshape(1, -1)
        
        # 标准化
        features_scaled = self.scaler.transform(features)
        
        # 预测
        cluster_label = self.kmeans.predict(features_scaled)[0]
        
        return cluster_label
    
    def label_mapping(self, cluster_label, labels, ground_truth=None):
        """将聚类标签映射到工况名称
        Args:
            cluster_label: 聚类标签
            labels: 历史聚类结果
            ground_truth: 人工标注的真实工况（可选）
        Returns:
            status: 工况名称
        """
        # 如果有人工标注，建立映射
        if ground_truth is not None:
            # 统计每个聚类的真实标签分布
            mapping = {}
            for i in range(self.n_clusters):
                mask = labels == i
                if mask.sum() > 0:
                    true_labels = np.array(ground_truth)[mask]
                    # 取最多的标签
                    unique, counts = np.unique(true_labels, return_counts=True)
                    mapping[i] = unique[np.argmax(counts)]
            
            return mapping.get(cluster_label, f"类别{cluster_label}")
        
        # 没有人工标注，按振动值排序推断
        # 通常：振动大→空载，振动小→满载（风机/泵类）
        cluster_centers = self.kmeans.cluster_centers_
        
        # 按第1维（RMS值）排序
        rms_values = cluster_centers[:, 0]
        sorted_indices = np.argsort(rms_values)[::-1]  # 从大到小
        
        # 建立映射
        status_names = ["空载", "半载", "满载"]
        mapping = {sorted_indices[i]: status_names[i] for i in range(len(sorted_indices))}
        
        return mapping.get(cluster_label, f"类别{cluster_label}")


# 使用示例

# 1. 训练阶段：用历史数据训练聚类模型

# status = cluster_model.label_mapping(cluster_label, labels)

# print(f"当前工况：{status}")
```

**实际应用流程：**

```
第1步：数据积累（前1-2周）
├── 只采集数据，不做判断
└── 积累不同工况下的振动数据

第2步：训练模型（第3周）
├── 提取特征（RMS、Peak、Kurtosis、主频幅值）
├── 用K-means聚类
└── 得到3个聚类中心

第3步：人工校准（第4周）
├── 运维人员标记：这个时间点是空载/半载/满载
├── 建立聚类标签和工况名称的映射
└── 调整聚类数量（如果3类不够）

第4步：正式使用
├── 实时振动数据 → 特征提取 → 预测工况
└── 根据工况选择对应的阈值
```

**不同设备类型的聚类特征：**

| 设备类型 | 关键特征 | 原因 |
|----------|----------|------|
| 风机/泵 | RMS + 主频幅值 | 空载转速高，振动大；满载转速略降 |
| 压缩机 | RMS + 周期性特征 | 不同负载时压缩周期不同 |
| 输送带 | RMS + 低频能量 | 空载振动小，有物料时振动大 |
| 破碎机 | RMS + 峭度 | 破碎时有冲击，峭度高 |

**优点：**
- 不需要额外传感器（0成本）
- 不需要设备方配合
- 纯软件实现

**缺点：**
- 需要1-2周数据积累
- 准确率略低（80-90%）
- 需要人工校准

**适用场景：**
- 老设备（没有负载信号）
- 设备方不愿配合
- 预算有限

### 七、老板常问的3个问题

**Q1：我的设备没有负载信号，怎么办？**

答：用方法2（电流估算）或方法3（振动聚类）。

**我的建议：**
- 预算够 → 装电流传感器（方法2，准确率更高）
- 预算紧 → 用振动聚类（方法3，零成本）
- 要求高 → 两个都用，互相验证

**Q2：工况识别准确率多少算合格？**

| 方法 | 合格线 | 优秀线 |
|------|--------|--------|

| 方法2 | 80% | 90% |

如果低于合格线，动态阈值的效果会打折扣。

**Q3：聚类模型需要多少数据？**

答：我的经验：

```
最少数据量：
├── 每种工况至少100个样本
├── 3种工况 × 100 = 300个样本
└── 如果每分钟1个样本，需要5小时

建议数据量：
├── 每种工况至少500个样本
├── 3种工况 × 500 = 1500个样本
└── 如果每分钟1个样本，需要25小时（1-2天）

实际考虑：
├── 设备不一定每天都经历所有工况
├── 建议积累1-2周数据
└── 覆盖不同时间段、不同负载情况
```

---

### 总结：工况识别的3个关键

1. **优先用现有信号**：有PLC负载信号就先读PLC
2. **电流是最实用的**：成本几十块，准确率85-90%
3. **聚类是备选方案**：零成本但需要数据积累
