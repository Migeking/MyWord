项目概述

项目背景

ai-controller-cli 是一款专为工业控制器设计的全功能命令行管理工具，支持本地（SSH）和远程（HTTP API）两种工作模式。项目命名为 AICtrl，旨在为工程师提供高效、统一的控制器管理体验。

设计原则

◈ 混合模式：自动检测本地（SSH）或远程（HTTP），无需手动切换
◈ 零依赖部署：可打包为独立二进制，支持无 Python 环境运行
◈ 模块化架构：命令模块与连接器解耦，易于扩展和维护
◈ 容错设计：网络异常自动重试，超时保护，清晰的错误提示
◈ 彩色输出：终端彩色输出，关键信息高亮，便于快速识别
◈ 进度显示：长时间操作显示进度条，提升用户体验

架构说明

连接管理器（Connectors）：自动检测目标类型，选择 SSH 或 HTTP API 模式。SSH 模式通过 subprocess 执行远程命令；HTTP 模式通过 requests 调用 Web API。


命令模块（Commands）：每个命令独立实现，通过连接器与控制器通信。支持本地和远程两种模式自动切换。


格式化器（Formatters）：统一输出格式，支持多种输出模式（普通/JSON/表格），终端自动检测并启用彩色输出。

命令设计

service
控制器服务管理：启动、停止、重启、查看状态
start stop restart status
deploy
部署配置文件和代码到控制器，支持热重载
--config <path> --logic <path> --hot-reload
logs
实时查看控制器日志，支持过滤和搜索
--tail <n> --level <INFO|WARN|ERROR> --grep <pattern>
monitor
实时监控点位数据，支持多点位同时监控
--points <alias1,alias2> --interval <sec> --format <table|json>
diag
系统诊断：通信状态、模块状态、配置检查
--full --module <name> --report
config
读取和修改控制器配置，支持 JSON 路径
get <key> set <key> <value> --export --import
backup
备份和恢复控制器配置及代码
create [<name>] restore <name> list

使用示例

1# 连接控制器（自动检测模式）
2$ aictrl connect 192.168.1.100 --user root
3
4# 查看控制器状态
5$ aictrl status
6
7# 部署配置和代码
8$ aictrl deploy --config ./config.json --logic ./logic.py --hot-reload
9
10# 实时监控点位
11$ aictrl monitor --points "泵1运行,水位,温度" --interval 1
12
13# 查看错误日志
14$ aictrl logs --level ERROR --tail 50
15
16# 系统诊断
17$ aictrl diag --full --report
