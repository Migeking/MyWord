**方式二：指定类型**
```

```
"帮我写一篇《传统企业AI落地最容易踩的3个坑》"

2. 套用对应的正文结构模板
3. 按照检测清单逐项检查
4. 生成完整的笔记草稿

我会给你一个完整的笔记草稿，包含：
- 标题选项（5-10个）
- 正文（符合你的风格）

## 4. 选题库使用

### 五大内容类型

| 类型 | 目的 | 写作要点 | 典型选题 |
|------|------|----------|----------|
| **避坑指南** | 吸引流量 | 每个坑有案例+解决方案 | AI转型最常见的3个坑 |
| **认知科普** | 建立专业 | 用人话讲专业内容 | AI到底能帮企业做什么 |
| **实操干货** | 提供价值 | 步骤清晰+有预算 | 企业AI落地第一步做什么 |
| **案例故事** | 展示实力 | 真实案例+可量化结果 | 我帮XX企业做诊断全过程 |
| **垂直领域** | 展示深度 | 技术+场景结合 | 设备预测性维护怎么做 |

### 选题选择建议

**按发布时间**:
| 时间 | 内容类型 |

| 周三 | 实操干货 |
| 周四 | 案例故事 |
| 周五 | 互动/转化 |

**按目标读者**:
- 老板/决策层 → 避坑指南、认知科普

## 5. 模板套用指南

### 5.1 标题模板

#### 揭秘型（最容易火）
```
"传统企业AI转型，最容易踩的3个坑"
"我观察了上百家企业，发现90%都做错了"
"一个20年老程序员看AI转型：这3个坑千万别踩"
```

#### 数字型
```
"老板最该关心的3个AI问题"
"90%的企业AI转型失败，原因是这5个"
"中小企业最容易成功的5个AI场景"
```

#### 对比型
```
"老板vs员工，看AI转型的3个差异"
"AI赋能前vsAI赋能后"
"别人的AI项目成功了，你的却失败？差在这3点"
```

#### 问题型
```
"你的企业真的需要AI吗？先问自己3个问题"
"为什么别人AI转型成功，���却失败？"
"AI落地第一步怎么做？先从这3个问题开始"
```

### 5.2 正文结构模板

#### 开头（3句话法则）
```
1. 身份背书：我是谁，做过什么
2. 痛点引入：我发现了什么问题
3. 价值承诺：这篇文章能帮你解决什么
```

**示例**:
> 我是鸡总，20年IT老兵，做过水务、冶金、零售各种系统。现在帮传统企业做AI转型诊断。
>
> 我观察了上百家企业做AI转型，发现90%的人都踩了同一个坑：把AI想得太简单。
>
> 今天说说最常见的3个坑，看看你踩了几个？

#### 中间（3点结构）
```
每个点用这个公式：
[观点] → [解释] → [案例/数据] → [解决方案]
```

**写作要点**:
- 每个点必须有真实案例或数据支撑
- 每个点必须给出具体解决方案
- 点与点之间有逻辑递进或并列关系

#### 结尾（引导转化）
```
1. 总结回顾（3个点用一句话总结）
2. 互动引导（评论区扣字/字母，引导评论）
3. 关注引导（人设强化）
```

**示例**:
> 以上3个坑，你踩过几个？
>
> 如果你正在做AI转型，或者想转型但不知道从哪开始，可以评论区扣"1"，我来帮你看看。
>
> 也欢迎关注"鸡总"，一个20年老程序员的转型思考。

## 6. 检测清单

### 标题检查
- [ ] 够不够痛？有没有数字？
- [ ] 是不是老板关心的问题？
- [ ] 有没有好奇心触发？

### 开头检查
- [ ] 3句话说清楚"你是谁+文章解决什么问题"？
- [ ] 身份背书有没有？
- [ ] 痛点引入有没有引发共鸣？

### 中间检查
- [ ] 3个点有没有案例/数据？
- [ ] 每个点有没有给出解决方案？
- [ ] 点与点之间有没有逻辑关系？

### 结尾检查
- [ ] 有没有互动引导（扣字/字母/数字）？
- [ ] 有没有引导关注？
- [ ] 有没有强化人设？

### 配图检查
- [ ] 封面图是否相关？
- [ ] 内文配图是否5张？
- [ ] AI绘图提示词是否给出？

## 7. 常见问题

### Q1: 内容不够干怎么办？
- **加数据**: 我观察了XX家企业，发现...
- **加案例**: 我帮XX企业做诊断时...
- **加步骤**: 第一步...第二步...第三步...
- **加清单**: 记住这3点/5点/7点

### Q2: 老板看不懂技术术语怎么办？
- **换成人话**: AI客服→"24小时帮你回答问题的机器人"
- **用比喻**: 就像请了一个永不疲倦的员工
- **用对比**: 以前要3天，现在3分钟

### Q3: 不知道怎么开头怎么办？
- **身份引入法**: 我是XX，做过XX，现在帮XX
- **数字引入法**: 我发现了XX%的企业都XX
- **问题引入法**: 很多老板问我XX问题

### Q4: 互动引导怎么写更自然？
- **问题引导**: 你们企业有XX问题吗？
- **选择引导**: 扣A/B/C/D，我帮你分析
- **数字引导**: 扣'1'，我发你XX

## 8. 示例：创作一篇笔记

### 用户输入
```
"帮我写一篇避坑指南，关于AI项目选型的"
```

### 我会做的

**Step 1: 匹配选题**
从选题库中选择最匹配的选题：
- "AI服务商不会告诉你的5个真相"（避坑指南类）
- "怎么找到靠谱的AI服务商？记住这3点"（实操类）
- "AI项目选型指南：记住这5点"（实操类）

**Step 2: 生成草稿**

标题选项：
1. **AI项目选型，90%的人都做错了这3点** ⭐
2. 我帮企业选了30个AI服务，总结出这5个避坑指南
3. 找AI服务商前，先问清楚这5个问题
4. 怎么找到靠谱的AI服务商？记住这3点
5. 老板必看：AI项目选型的5个坑

正文结构：
```
开头：身份+痛点引入
第1个坑：只听概念不看案例
第2个坑：只看价格不看价值
第3个坑：只想一步到位
结尾：总结+互动引导
```

**Step 3: 输出完整笔记**
包含：
- 5-10个标题选项
- 完整正文（约650字）
- 5张配图建议+AI绘图提示词
- 发布时间建议
- 互动引导话术
- 标签建议
- 检测清单（已勾选）
