Transformer 图解
01 · 背景
RNN 的瓶颈
RNN 必须按顺序逐个处理 token
无法并行计算，训练速度慢
长序列存在信息丢失问题
→ 需要全新架构
Transformer 图解
02 · 核心创新
自注意力机制
一眼看全局
每个 token 同时关注所有其他 token
一步捕获全局依赖关系
可并行计算，效率远超 RNN
Self-Attention
同时看见整个序列
Transformer 图解
03 · 注意力三要素
Query · Key · Value
Query（查询）
你提出的问题
Key（键）
所有文档的标题
Value（值）
文档的实际内容
Query 匹配 Key → 得到权重 → 加权求和 Value
Transformer 图解
04 · 并行视角
多头注意力
多角度理解
并行运行多组 QKV 计算
一个头关注语法结构
另一个头关注语义相似度
所有头的输出拼接在一起
Transformer 图解
05 · 整体架构
编码器 · 解码器
Encoder（编码器）
输入 → 自注意力 → 前馈网络 → 特征
↓
Decoder（解码器）
自注意力 → 交叉注意力 → 前馈网络 → 输出
编码器提取特征，解码器逐步生成

正余弦函数为每个位置生成唯一编码
