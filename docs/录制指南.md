# AI落地残酷真相 - 视频录制指南

## 快速开始（推荐）

### 方法A: OBS 录制（最简单）

1. **下载 OBS Studio** (免费): https://obsproject.com
2. **安装后打开**，添加"浏览器"源
   - 源设置：
     - URL: `D:\code\MyWord\xhs-animated.html`
     - 宽度: 390
     - 高度: 844
     - CSS: `body { overflow: hidden; }`
3. **设置录制**:
   - 输出 → 录像 → 格式: **MP4**
   - 录像编码器: **H.264**
   - 分辨率: 1080x1920（或用390x844）
4. **设置场景**:
   - 缩放浏览器源铺满画面
   - 可添加纯色源作为背景
5. **开始录制** → 播放动画 → 停止录制

---

### 方法B: ffmpeg 屏幕录制

需要安装 ffmpeg（可通过 `winget install ffmpeg` 或 https://ffmpeg.org）

```powershell
# 基础命令 - 录制屏幕
ffmpeg -f gdigrab -framerate 30 -i title="xhs-animated.html" -c:v libx264 -crf 18 output.mp4
```

## 视频发布规格（小红书）

| 参数 | 要求 |
|------|------|
| 比例 | 9:16 (竖屏) |
| 分辨率 | 1080×1920（推荐）|
| 时长 | 15-60秒 |
| 格式 | MP4 (H.264) |
| 大小 | ≤ 250MB |

---

## 录制参数建议

**OBS 设置**:
- 基础分辨率: 390×844
- 输出分辨率: 1080×1920
- 缩放算法: **Lanczos**
- 帧率: 30fps
- 录像质量: 高质量 (CRF 18-22)

**后期处理**（可选）:
```bash
# 压缩视频
ffmpeg -i input.mp4 -vf "scale=1080:1920" -c:v libx264 -crf 22 output_compressed.mp4
```

## 备选方案：在线工具

如果不方便本地录制，可用以下在线工具把长图转视频：
1. **Canva** (canva.com) - 有视频编辑功能，支持1080x1920
2. **剪映** (字节跳动) - 导入图片序列，添加动画
3. **CapCut** - 类似剪映

## 录制流程（简化版）

```
1. 打开 xhs-animated.html
2. 点击 ▶ 自动播放（或手动 ← → 浏览）
3. OBS 录制
4. 停止 → 导出 MP4
5. 上传小红书
```

> 建议先试录一遍（3-5秒）确认效果，再录完整版。
