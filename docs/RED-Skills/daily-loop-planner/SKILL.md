# 每日计划与复盘循环

让每一天有始有终：早晨定目标、拆任务、排时间块；白天跟踪进展；晚间复盘完成度、沉淀经验、衔接明日。适合与 AI 结对工作的人，也适合任何想建立稳定日循环的个人。

## 这个技能是什么

一个由 AI 引导的每日工作循环：

- **早晨计划（Plan）**：把模糊的"今天想做什么"拆成可执行的目标、优先级和时间块，写下一句当日承诺。
- **执行跟踪（Do）**：白天用待办清单记录进展，随手标记完成、阻塞、变更。
- **晚间复盘（Review）**：对照计划统计完成度，分析障碍，提炼经验，并为明天留好衔接。

AI 的角色是**引导者与记录者**：向你提问、帮你结构化、把结果写入你指定的工作目录。AI 不会代替你执行任务，也不会触碰工作目录之外的任何文件。

## 为什么需要

- AI 会话之间缺少上下文，每次开场都要重新对齐"上次做到哪了"。一个可追溯的日循环让任何新会话都能快速接上。
- 只计划不复盘，错误会重复发生；只复盘不计划，方向会漂移。两个环节缺一不可。
- 完成度数字让"今天到底干了什么"一目了然，也让你对自己有交代。

## 适用场景

**适合：**
- 每天早上想清楚当天最重要的几件事
- 多任务并行，需要给任务排优先级和时间块
- 希望量化每日产出、识别反复出现的障碍
- 需要跨会话延续工作上下文（AI 协作、个人项目管理）

**不适合：**
- 代替你思考或自动执行任务（本技能只引导与记录）
- 自动发布、自动打卡等对外行为（本技能不含任何自动发布功能）

## 完整循环总览

```
早晨 · Plan ──► 白天 · Do ──► 晚间 · Review ──► 明天
   │                 │                 │
   │ 拆解目标         │ 跟踪待办         │ 统计完成度
   │ 排优先级         │ 记录阻塞         │ 分析障碍
   │ 安排时间块       │ 随手写备注       │ 沉淀经验
   │ 写下当日承诺     │                 │ 衔接明日
   └────────────────┴────────────────┘
        （复盘产出直接喂给明早的计划）
```

## 一、早晨计划（Plan）

### 输入

- 昨天复盘里"明日衔接"的内容（如果有）
- 未完成的任务清单 / 项目待办
- 你手头的截止日期、阻塞项、今天的精力安排

### 流程

AI 引导你依次完成五步，并把结果写入计划文件：

1. **目标拆解**：把"今天想完成什么"写成 1~3 个具体目标，每个目标一句话能说清"交付什么"。
2. **优先级排序**：给任务标 P0（必须完成）、P1（应该完成）、P2（有时间再做）。
3. **时间块**：为关键任务安排具体时间块（如 09:00–11:00 深挖任务 A），把最难的事放在精力最好的时段。
4. **今日重点**：圈出今天最值得投入的一件事，避免贪多。
5. **当日承诺**：写下一句承诺（"今天结束时，我将交付……"），晚上用它做验收。

### 计划模板

```markdown
# 计划 · YYYY-MM-DD

## 核心目标
- 一句话描述今天最重要的成果

## 任务列表
| 优先级 | 任务 | 预计耗时 | 时间块 | 状态 |
|--------|------|----------|--------|------|
| P0     | 任务A | 2h      | 09:00-11:00 | ⬜ |
| P1     | 任务B | 1h      | 14:00-15:00 | ⬜ |
| P2     | 任务C | 0.5h    | 灵活      | ⬜ |

## 今日重点
- 只做一件最重要的事：______

## 预期成果
- 完成任务A，并通过验收
- 提交阶段性成果 / 发给相关人

## 阻塞项
- 需要谁或什么条件才能推进：______

## 当日承诺
- 今天结束时，我将交付：______
```

### 示例

```markdown
# 计划 · 2026-08-02

## 核心目标
完成公众号选题的初稿大纲，并确定本周发布排期。

## 任务列表
| 优先级 | 任务 | 预计耗时 | 时间块 | 状态 |
|--------|------|----------|--------|------|
| P0     | 整理上周数据，写选题大纲 | 2h | 09:00-11:00 | ⬜ |
| P1     | 与排版确认模板调整 | 1h | 14:00-15:00 | ⬜ |
| P2     | 收集 3 篇竞品参考 | 0.5h | 灵活 | ⬜ |

## 今日重点
- 大纲初稿（这是今天的锚点，其他都可让路）

## 预期成果
- 大纲 v1 有清晰的三段结构与 5 个数据点
- 排期表更新到本周五

## 阻塞项
- 排版模板的最终版还没回，下午跟进一次

## 当日承诺
- 今天结束时，我将交付：一份可发给团队的选题大纲 v1
```

## 二、执行跟踪（Do）

白天无需写长文，随手维护计划文件里的状态即可：

| 状态 | 含义 |
|------|------|
| ⬜ 未开始 | 已列入计划，尚未动手 |
| 🔄 进行中 | 已完成部分，可附进度百分比 |
| ✅ 已完成 | 交付完毕，可附一句结果 |
| ⛔ 阻塞 | 卡住了，写明障碍与求助对象 |
| ➖ 取消 | 主动放弃，写明原因 |

约定：完成一件事就顺手标 ✅；遇到阻塞立刻标 ⛔ 并写一句原因。这些随手标记是晚上复盘的原料。

## 三、晚间复盘（Review）

### 输入

- 当日计划文件（含执行跟踪的状态标记）
- 你回忆中的实际产出、花掉的时间、遇到的卡点

### 流程

AI 引导你依次完成四步，并把结果写入复盘文件：

1. **完成度统计**：逐项对照计划，统计完成、部分完成、未完成的数量，算出完成率。
2. **障碍分析**：对未完成或卡住的任务，多问一层"卡在哪、为什么"，识别真正的障碍。
3. **经验沉淀**：提炼至少一条"值得保持"的正面经验，和一条"下次要改"的负面经验。
4. **明日衔接**：把未完成的事项和今日教训，转写成明天计划的第一行输入，并给出明日预测。

### 复盘模板

```markdown
# 复盘 · YYYY-MM-DD

## 完成情况
- ✅ 任务A：已完成（一句话结果）
- 🔄 任务B：部分完成（进度 50%，剩 X 未做）
- ❌ 任务C：未完成（原因）
- 完成率：X / Y 项，约 Z%

## 障碍分析
- 障碍1：______ → 卡在：______ → 下次可：______
- 障碍2：______ → 卡在：______ → 下次可：______

## 经验教训
- 正面：______ 做法有效，值得保持
- 负面：______ 导致效率下降，需要改进

## 明日衔接
- 继续推进：任务B，注意上次的卡点
- 尝试新方法：______

## 信心评分
- 今日信心：7/10
- 明日预测：8/10
```

### 示例

```markdown
# 复盘 · 2026-08-02

## 完成情况
- ✅ 整理数据并写出大纲：已完成，三段结构 + 5 个数据点
- 🔄 与排版确认模板：部分完成，模板未最终定稿
- ❌ 收集竞品参考：未完成，下午被会议占掉
- 完成率：1 项完成 / 1 项部分 / 1 项未完成，约 40%

## 障碍分析
- 模板未定稿 → 卡在排版同事出差 → 下次提前 2 天发需求
- 竞品参考没做 → 卡在时间被会议挤占 → 挪到早上或碎片时间处理

## 经验教训
- 正面：先搭大纲框架再填数据，推进顺畅
- 负面：把低优先级任务排在下午，容易被会议挤掉

## 明日衔接
- 继续推进：催排版模板（已提前提醒），完成竞品参考（挪到 09:00）
- 尝试新方法：把 P2 任务拆成 15 分钟的碎片任务

## 信心评分
- 今日信心：7/10
- 明日预测：8/10
```

## 四、使用流程（一天完整走一遍）

1. **早晨开场**（建议开工前）：告诉 AI "开始今日计划"，AI 按第一节流程提问并生成计划文件。
2. **确认写入位置**：首次使用时，由你指定工作目录和文件名规则（如 `计划/YYYY-MM-DD.md`）。AI 只写入你指定的位置，其余文件一律不碰。
3. **白天跟踪**：随手用状态标记更新计划文件；需要时让 AI 帮你汇总当前进度。
4. **晚间收尾**：告诉 AI "开始今日复盘"，AI 按第三节流程生成复盘文件。
5. **新旧衔接**：复盘文件中的"明日衔接"自动成为明天计划的输入，完成一次循环。
6. **（可选）周度小结**：每周日或周一，把 7 天复盘汇总成一句趋势：完成率走势、反复出现的障碍、值得固化的经验。

## 五、质量验收清单

每次循环结束，对照自查：

**计划环节**
- [ ] 有 1~3 个能用一句话说清的核心目标
- [ ] 每个任务标了优先级（P0/P1/P2）
- [ ] 关键任务安排了具体时间块
- [ ] 有明确的"今日重点"（只圈一件最重要的事）
- [ ] 写下了当日承诺
- [ ] 列出的阻塞项都有下一步动作

**跟踪环节**
- [ ] 完成的任务随手标 ✅
- [ ] 卡住的任务标 ⛔ 并写了原因
- [ ] 状态与实际进度一致

**复盘环节**
- [ ] 完成度有数字（完成 / 部分 / 未完成 + 完成率）
- [ ] 每个未完成项都做了障碍分析（不是一句"没时间"带过）
- [ ] 至少一条正面经验 + 一条负面经验
- [ ] 有明确的"明日衔接"，且能直接喂给明天的计划
- [ ] 今日信心与明日预测已打分

**总原则**
- [ ] 全流程只发生在你指定的工作目录内，无任何隐藏行为
- [ ] 计划与复盘内容由你确认，AI 只引导与记录

## 使用提示

1. 计划控制在 5 分钟以内，别把早上耗在排计划上。
2. 优先级 P0 的任务不要超过 3 个，多了等于没有重点。
3. 复盘时对"障碍"多问一层"为什么"，比直接写"没时间"更有价值。
4. 复盘的"明日衔接"是明天的起点，务必写，别省。
5. 如果某天没执行计划，晚上仍花 2 分钟复盘一句"为什么没执行"，这本身就是最有用的经验。
6. 需要向上汇报时，可让 AI 按"昨日完成 / 今日计划 / 阻塞项"三行生成简报。
