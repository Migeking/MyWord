# 常用评标办法说明

## 一、综合评分法

### 适用场景
适用于技术复杂、服务质量要求高的项目，如工程勘察设计、软件开发、咨询服务等。

### 评分构成

```
综合得分 = 技术得分 × 技术权重 + 商务得分 × 商务权重 + 价格得分 × 价格权重
```

### 常见权重配置

| 项目类型 | 技术权重 | 商务权重 | 价格权重 |
|----------|----------|----------|----------|
| 工程设计 | 50% | 10% | 40% |
| 软件开发 | 60% | 15% | 25% |
| 咨询服务 | 70% | 10% | 20% |
| 设备采购 | 30% | 10% | 60% |

### 价格得分计算方法

#### 方法一：基准价法
```
价格得分 = 价格权重 × (基准价 / 投标报价) × 100
或
价格得分 = 价格权重 × [100 - |投标报价 - 基准价| / 基准价 × 100 × n]
```

其中基准价可为：
- 所有有效投标报价的平均值
- 平均值下浮一定比例（如5%）
- 招标控制价下浮一定比例

#### 方法二：最低价优先法
```
价格得分 = 价格权重 × (最低有效报价 / 投标报价) × 100
```

### 技术评分标准示例

| 评分项 | 分值 | 评分标准 |
|--------|------|----------|
| 技术方案 | 20分 | 方案完整性、可行性、创新性 |
| 项目团队 | 15分 | 人员配置、资质、经验 |
| 实施计划 | 10分 | 进度安排、里程碑设置 |
| 质量保证 | 10分 | 质量管理体系、控制措施 |
| 服务承诺 | 10分 | 响应时间、培训、售后 |

## 二、最低价评标法

### 适用场景
适用于技术要求标准化、规格统一的项目，如通用设备采购、标准化工程等。

### 评标流程

```
第一步：资格审查
第二步：符合性审查（技术响应是否满足）
第三步：按报价从低到高排序
第四步：推荐最低报价且符合要求的投标人中标
```

### 注意事项

- 必须设置技术符合性门槛，防止低价劣质中标
- 可设置成本警戒线，报价低于成本可能被废标
- 需明确技术偏离的处理规则

### 风险提示

| 风险 | 说明 | 应对措施 |
|------|------|----------|
| 低价恶性竞争 | 投标人故意报低价中标 | 设置成本警戒线、履约保证金 |
| 偷工减料 | 中标后降低质量 | 严格验收标准、质量保证金 |
| 无法履约 | 低价中标后无法完成 | 资格审查、履约能力评估 |

## 三、两阶段评标法

### 适用场景
适用于大型复杂项目，需要先评估技术方案再评估价格。

### 评标流程

```
第一阶段：技术评标
  → 投标人提交技术方案（不含报价）
  → 专家评审技术方案
  → 确定技术合格的投标人名单

第二阶段：商务评标
  → 技术合格投标人提交报价
  → 进行价格评分
  → 综合推荐中标候选人
```

### 优点
- 防止技术方案抄袭报价信息
- 确保技术方案质量优先
- 减少低价对技术评估的干扰

---

## 四、经评审的最低投标价法

### 适用场景
适用于具有通用技术、性能标准的项目。

### 评标流程

```
第一步：初步评审（资格、符合性）
第二步：详细评审（按招标文件约定方法）
第三步：计算评标价（投标报价 + 修正因素）
第四步：按评标价排序推荐中标候选人
```

### 评标价修正因素

| 修正因素 | 说明 |
|----------|------|
| 技术偏离修正 | 技术偏离按约定标准扣减/增加 |
| 商务偏离修正 | 付款条件、质保期等偏离修正 |
| 其他修正 | 按招标文件约定的其他因素 |

---

## 五、竞争性谈判法

### 适用场景
- 招标后无合格投标人
- 技术复杂、性质特殊，不能确定详细规格
- 时间紧急，无法按招标程序进行

### 流程

```
第一步：发布谈判公告或邀请
第二步：成立谈判小组
第三步：制定谈判文件
第四步：与供应商进行多轮谈判
第五步：确定成交供应商
```

---

## 六、评标办法选择建议

| 项目特征 | 推荐评标办法 |
|----------|--------------|
| 技术复杂、服务质量关键 | 综合评分法 |
| 标准化产品、技术差异小 | 最低价评标法 |
| 大型复杂项目、防抄袭 | 两阶段评标法 |
| 有技术偏离需要量化 | 经评审最低价法 |
| 特殊情况、紧急需求 | 竞争性谈判法 |

## 七、评标常见问题

### 废标情形

| 序号 | 废标情形 |
|------|----------|
| 1 | 投标文件逾期送达 |
| 2 | 投标人资格不符合要求 |
| 3 | 投标文件未密封或密封破损 |
| 4 | 投标函未签字盖章 |
| 5 | 投标保证金未缴纳或不足 |
| 6 | 投标有效期不足 |
| 7 | 报价超过招标控制价 |
| 8 | 关键技术指标不响应 |
| 9 | 投标文件内容前后矛盾 |
| 10 | 投标人相互串通投标 |

### 评分争议处理

| 情况 | 处理方法 |
|------|----------|
| 评分差异大 | 要求评委说明理由 |
| 评分明显错误 | 要求评委更正 |
| 评分标准理解不一 | 澄清评分标准后重新评分 |
