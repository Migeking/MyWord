# bidding-assistant

招投标全流程智能助手 — 支持招标与投标双场景，覆盖招投标全流程核心工作。

## 功能概览

### 招标方功能
- 招标需求分析与招标文件编制
- 评标辅助与投标文件评审
- 评分表生成与报价对比分析

### 投标方功能
- 招标文件深度分析
- 投标策略制定与竞争分析
- 投标文件编制与响应矩阵构建
- 废标风险检查与应对建议

## 快速开始

### 招标方使用

```
用户：我要招标采购一套污水处理设备，帮我编制招标文件
AI：进入招标方模式，引导收集项目信息，输出标准招标文件
```

### 投标方使用

```
用户：这是招标文件，帮我分析投标要点和风险
AI：输出招标文件分析报告，包含资格条件、技术要求、评分标准、风险提示
```
