# bidding-assistant

招投标全流程智能助手，帮助用户高效完成招标或投标工作。

## 双场景定位

本 Skill 同时支持两种角色：

| 角色 | 核心目标 | 主要工作流 |
|------|----------|-----------|
| **招标方** | 编制招标文件、组织评标、确定中标人 | 需求分析 → 招标文件编制 → 发布公告 → 开标评标 → 定标 |
| **投标方** | 编制投标文件、响应招标要求、争取中标 | 招标文件分析 → 策略制定 → 投标文件编制 → 提交响应 |

---

## 一、招标方工作流

### 1.1 招标需求分析

**触发词**：「我要招标」「编制招标文件」「招标需求分析」

**流程**：
```
项目背景 → 采购范围界定 → 资格条件设定 → 评标办法选择 → 时间计划
```

**关键输出**：
- 采购需求说明书
- 投标人资格条件清单
- 评标办法（综合评分法/最低价评标法等）
- 招标时间计划表

### 1.2 招标文件编制

**触发词**：「写招标文件」「招标书」「编制招标文件」

**标准结构**：

```
第一卷 投标须知
├── 投标须知前附表
├── 总则
├── 招标范围及要求
├── 投标文件编制要求
├── 投标文件的递交
└── 开标与评标

第二卷 技术规范与要求
├── 技术规格书
├── 服务要求
└── 验收标准

第三卷 合同条款
├── 通用条款
└── 专用条款

第四卷 投标文件格式
├── 投标函
├── 法定代表人授权书
├── 资格证明文件
├── 技术方案
├── 商务报价
└── 其他材料
```

### 1.3 评标辅助

**触发词**：「评标」「打分」「投标文件评审」

**支持功能**：
- 投标文件符合性检查（是否响应招标要求）
- 评分表自动生成
- 投标报价对比分析
- 技术方案评分建议
- 风险提示（不平衡报价、漏项等）

## 二、投标方工作流

### 2.1 招标文件分析

**触发词**：「分析招标文件」「投标分析」「解读招标文件」

**分析维度**：

| 维度 | 分析要点 |
|------|----------|
| **资格条件** | 是否满足硬性条件（资质、业绩、人员等） |
| **技术要求** | 核心技术指标、特殊要求、否决项 |
| **评分标准** | 权重分布、得分要点、失分风险 |
| **商务要求** | 报价要求、付款条件、保证金 |
| **时间节点** | 质疑截止、投标截止、开标时间 |
| **风险提示** | 模糊条款、苛刻条件、陷阱条款 |

**输出物**：《招标文件分析报告》（见 `templates/bidding-analysis-report.md`）

### 2.2 投标策略制定

**触发词**：「投标策略」「中标策略」「竞争分析」

**策略制定框架**：

```
1. 自身评估
   ├── 资格条件匹配度
   ├── 技术优势与劣势
   ├── 价格竞争力
   └── 业绩支撑

2. 竞争分析
   ├── 潜在竞争对手识别
   ├── 竞品优劣势对比
   └── 市场份额与历史中标情况

3. 策略选择
   ├── 技术领先策略（技术标突出）
   ├── 价格竞争策略（低价中标导向）
   ├── 综合优势策略（技术+商务平衡）
   └── 差异化策略（特色亮点）

4. 风险评估
   ├── 废标风险点
   ├── 得分风险点
   └── 应对措施
```

### 2.3 投标文件编制

**触发词**：「写投标文件」「投标书」「技术标书」「商务标书」

**编制流程**：

```
第一步：响应矩阵构建
  → 将招标要求逐条列出，对应投标响应

第二步：资格文件准备
  → 营业执照、资质证书、业绩证明、人员证书等

第三步：技术方案编制
  → 根据评分标准，逐项撰写技术响应

第四步：商务报价编制
  → 成本测算 → 报价策略 → 报价表编制

第五步：整合审核
  → 格式检查 → 内容一致性 → 签章齐全
```

**响应矩阵示例**：

| 招标要求 | 投标响应 | 响应位置 | 备注 |
|----------|----------|----------|------|
| 投标人须具备XX资质 | 具备，证书编号XXX | 资格文件P5 | 完全响应 |
| 项目经理须持有一级建造师证 | 具备，证书编号XXX | 资格文件P8 | 完全响应 |
| 提供3年以上质保 | 承诺提供5年质保 | 技术方案P12 | 超越响应 |

### 2.4 标书审核

**触发词**：「审核投标文件」「标书检查」「废标风险检查」

**审核清单**（见 `references/bidding-checklist.md`）：

**形式审核**：
- [ ] 投标文件签字盖章是否齐全
- [ ] 是否按规定装订、密封
- [ ] 投标保证金是否按时缴纳
- [ ] 投标有效期是否符合要求
- [ ] 投标文件份数是否满足

**实质审核**：
- [ ] 是否完全响应招标文件的实质性要求
- [ ] 技术方案是否满足技术规格
- [ ] 报价是否在控制价范围内
- [ ] 业绩证明是否符合要求
- [ ] 人员配置是否满足要求

**风险审核**：
- [ ] 是否存在不平衡报价风险
- [ ] 是否存在漏项
- [ ] 是否存在前后矛盾
- [ ] 是否存在超范围承诺

## 五、使用示例

### 招标方示例

```
用户：我要招标采购一套污水处理设备，帮我编制招标文件
AI：好的，我来帮您编制招标文件。请提供以下信息：
    1. 项目名称、采购预算
    2. 设备技术规格要求
    3. 投标人资格条件
    4. 评标办法偏好（综合评分法/最低价法）
    5. 投标截止时间
```

### 投标方示例

```
用户：这是招标文件，帮我分析一下投标要点和风险
AI：我来分析招标文件，输出：
    1. 资格条件清单（是否满足）
    2. 技术要求重点与难点
    3. 评分标准分析
    4. 废标风险点提示
    5. 投标策略建议
```
