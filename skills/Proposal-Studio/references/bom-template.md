# 产品/商务清单（BOM）标准模板

> 使用说明：根据方案选择的产品，按本模板生成清单，优先输出为腾讯文档表格。
> 重要提示：价格仅作参考，正式报价须另行出具报价单。

---

## 格式说明

### BOM 表字段说明

| 字段 | 说明 | 必填 |
|------|------|------|
| 序号 | 从1开始顺序编号 | ✅ |
| 设备名称 | 标准产品名称，不可使用缩写 | ✅ |
| 规格型号 | 完整型号，包含关键参数 | ✅ |
| 品牌 | 选型品牌（国产/进口须注明） | ✅ |
| 单位 | 台/套/批/个/米 | ✅ |
| 数量 | 整数，含小数时注明 | ✅ |
| 单价(¥) | 含税参考价 | ✅ |
| 总价(¥) | = 单价 × 数量 | ✅ |
| 交货期 | 订货后___周 | 建议填 |
| 备注 | 质保期/特殊情况说明 | 建议填 |

---

## 标准商务条款

| 条款 | 标准内容 | 可调整范围 |
|------|---------|-----------|
| 含税价格 | 含13%增值税 | 如需专票另行注明 |
| 交货期 | 合同签订后4-8周 | 根据设备类型调整 |
| 付款方式 | 预付30%，到货30%，验收40% | 大项目可分四期 |
| 质保期 | 设备验收合格后2年 | 进口品牌可协商 |
| 技术支持 | 7×24h远程支持，2次现场服务 | 可按需增加 |
| 报价有效期 | 30天 | 原材料波动时缩短 |
| 运输方式 | 送达项目现场，含运费 | 西藏/新疆另行计算 |
| 验收方式 | 到货验收+调试验收 | 按合同约定 |

## 价格浮动说明模板

> ⚠️ **价格提示**：因市场供需及汇率波动，以下产品在订货时可能产生价格浮动：
> - 进口品牌传感器/仪表：±5%浮动
> - PLC/DCS控制系统：±3%浮动
> - 特殊规格/非标产品：±10%浮动
> 浮动超出上述范围时，我司将提前书面通知买方确认。

## 输出规范

1. **文件命名**：`YYYYMMDD_[客户]_[类型]_[版本].xlsx`
   - 示例：`20260517_XX水厂_BOM清单_V1.0.xlsx`
2. **表头配色**：使用蓝色表头（#1F4E79），白色字体
3. **金额合计行**：加粗显示，背景填充浅蓝（#D6E4F0）
4. **待确认格**：标注「待确认」，字体用红色（#FF0000）
5. **正文行高**：22pt，Excel可自动设置
