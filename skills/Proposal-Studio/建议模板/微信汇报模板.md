# 微信汇报模板库

> 用途：在方案/清单/报告完成后，通过微信发送标准化通知
> 使用场景：方案完成通知、客户跟进、进度汇报、确认提醒

## 十、微信消息发送规范

### 10.1 消息结构建议

| 要素 | 建议 | 示例 |
|------|------|------|
| 标题 | 简短明确 | 📋 方案完成通知 |
| 正文 | 分点列举 | 使用 • 或数字列表 |
| 附件 | 说明数量和名称 | 📎 3个文件 |
| 行动 | 明确要求 | 请XX日前回复 |
| 签名 | 署名+联系方式 | XXX 敬上 |

### 10.2 消息长度控制

- 简短通知：不超过200字
- 详细报告：可分多条发送
- 重要文件：先发说明，再发附件

### 10.3 消息格式选择

```
纯文本：简单事项
Markdown：需要强调重点
表格：数据类内容
截图：可视化内容
```
