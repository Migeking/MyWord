# 微信通知集成方案

> 说明：本技能包目前不包含微信发送功能，以下是建议的集成方案

---

## 方案一：企业微信Webhook（推荐，免费）

### 步骤1：获取Webhook地址

1. 企业微信 → 「群聊」→ 创建群聊
2. 添加「群机器人」
3. 复制Webhook地址

### 步骤2：创建通知脚本

```python
# scripts/wechat_notify.py
import requests
import json
from datetime import datetime

def send_wechat_notify(webhook_url, message):
    """
    发送企业微信消息
    参数：
        webhook_url: 企业微信群机器人webhook地址
        message: 消息内容（字典格式）
    """
    headers = {'Content-Type': 'application/json'}
    data = {
        "msgtype": "markdown",
        "markdown": {
            "content": message
        }
    }
    response = requests.post(webhook_url, headers=headers, data=json.dumps(data))
    return response.json()

# 使用示例
if __name__ == "__main__":
    webhook = "https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=XXXXX"
    message = """**📋 方案完成通知**

    **项目**：XXX技术方案
    **状态**：✅ 已完成 V1.0
    **时间**：2026-05-17

    **附件**：
    - 技术方案.docx
    - 产品清单.xlsx

    请确认回复。"""
    
    result = send_wechat_notify(webhook, message)
    print(result)
```

## 方案二：钉钉Webhook（免费）

### 步骤1：获取Webhook地址

1. 钉钉群 → 设置 → 智能群助手
2. 添加机器人 → 自定义
3. 复制Webhook地址

### 步骤2：创建通知脚本

```python
# scripts/dingtalk_notify.py
import requests
import json

def send_dingtalk_notify(webhook_url, message):
    """
    发送钉钉消息
    """
    headers = {'Content-Type': 'application/json'}
    data = {
        "msgtype": "markdown",
        "markdown": {
            "title": "方案完成通知",
            "text": message
        }
    }
    response = requests.post(webhook_url, headers=headers, data=json.dumps(data))
    return response.json()
```

## 建议的标准化消息格式

```markdown
📋 **方案完成通知**

**项目**：{项目名称}
**类型**：技术方案/产品清单/调研报告
**版本**：V1.0
**完成时间**：{YYYY-MM-DD HH:mm}

**主要内容**：
• {要点1}
• {要点2}
• {要点3}

**附件**：{数量}个文件

✅ 请确认回复，如有修改意见请直接指出。
```

## 集成建议

1. **推荐企业微信**：免费、稳定、适合团队使用
2. **webhook限制**：每分钟最多20条消息
3. **消息格式**：建议使用markdown格式，美观易读
4. **敏感信息**：不要在消息中发送敏感信息（密码、密钥等）
