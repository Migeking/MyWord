### 1.2 工作流分析

```
阶段1：现场调研 → 阶段2：需求分析 → 阶段3：方案撰写 → 阶段4：清单输出
   ↓                    ↓                    ↓                    ↓
 触发词：               触发词：              触发词：              触发词：
「现场调研」           「需求规格」          「写方案」            「清单」
「调研报告」           「分析一下」          「技术方案」          「BOM」
「走访报告」                                 「投标方案」          「报价」
```

**优点**：
- ✅ 四阶段流程清晰，逻辑递进
- ✅ 核心原则明确（AI不代替人调研）
- ✅ 触发词设计合理，便于自动识别
- ✅ 行业覆盖三大领域（IoT/水务/自控）

**不足**：
- ⚠️ 模板内容较为通用，缺少具体行业深度
- ⚠️ 缺少与微信等即时通讯的集成说明
- ⚠️ 未明确AI输出格式（Word/腾讯文档的具体要求）
- ⚠️ 缺少质量检查清单的具体操作指引

## 二、模板优化建议

### 2.1 SKILL.md 优化建议

**问题1：触发词覆盖不全**
```markdown
# 当前
触发词：「现场调研」「调研报告」「填调研」「走访报告」「现场勘验」

# 建议补充
「需求调研」「现场勘验」「现场勘察」「现场勘查」「现场复核」「现场确认」
```

**问题2：缺少错误处理**
```markdown
# 建议增加
## 常见问题处理

| 问题 | 处理方式 |
|------|---------|
| 客户无法提供完整信息 | 标注「待确认」，不影响后续章节 |
| 调研结果与方案矛盾 | 返回阶段1，重新确认需求 |
| 行业类型不明确 | 先确认行业，再加载对应模板 |
```

**问题3：缺少输出质量标准**
```markdown
# 建议增加
## 输出质量标准

- 方案文档：不少于X页，章节完整率100%
- BOM清单：金额合计误差≤±1%
- 调研报告：客户签字确认率100%
```
