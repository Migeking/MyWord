# 无人机智能管控平台 · AI 增强项目管理方案

> 单文件 SPA · 双击 `index.html` 即可打开 · 离线可用

## 一、这是什么

基于 `项目管理生命周期流程表_无人机智能管控平台(1).xlsx` 整理输出的**新一代项目管理方案**，主张：

> **瀑布定边界 · 敏捷做交付 · AI 强决策**

不是再造一个项目管理软件，而是把原 Excel 表中：
- 5 阶段 10 节点的生命周期
- 6 迭代的敏捷落地
- 10×6 的 RACI 责任矩阵
- 19 个 AI 决策点

整合为一个**可双击打开、可分享、可演示**的单文件方案页。

项目管理AI增强方案/

## 三、如何打开

### 方式 1：双击（最简单）
直接双击 `index.html`，默认浏览器打开即可。

### 方式 2：浏览器拖拽
把 `index.html` 拖到 Chrome / Edge / Firefox 窗口。

### 方式 3：本地 HTTP（推荐用于演示）
部分浏览器对 `file://` 协议下的 Google Fonts 加载有限制。如果页面字体回退到默认无衬线，用以下任一方式启动本地 HTTP：

```powershell
# 在 项目管理AI增强方案/ 目录下执行
python -m http.server 8080
# 然后访问 http://localhost:8080
```

或 PowerShell 一行：

```powershell
cd 'd:\code\MyWord\项目管理AI增强方案'
python -m http.server 8080
```

## 四、页面结构

| Tab | 模块 | 内容 |
|---|---|---|
| **01 总览** | Overview | 价值主张、三色关系图、五维度对比、KPI 看板 |
| **02 生命周期** | Lifecycle | 5 阶段 10 节点时间轴，每节点含输入/输出/角色/AI 决策点 |
| **03 敏捷迭代** | Agile | 6 迭代卡片墙 + 5 项原则 + 与瀑布阶段对应 |
| **04 AI 决策引擎** | AI | 决策管道图、19 个决策卡、决策日志样例 |
| **05 RACI 矩阵** | RACI | 10 阶段 × 6 角色完整矩阵 + 标识说明 |
| **06 管控看板** | Dashboard | 4 关键指标、5 风险预警、6 复盘清单 |

**左侧阶段进度条**：可视化当前 Tab 对应的阶段位置。
**Tab 切换**：支持 URL Hash 持久化（`#ai` / `#lifecycle` 等），可分享锚点链接。

## 五、设计说明

### 美学方向
**Industrial Editorial（工业杂志感）**
- 深色基底 `#0A0E1A` + 网格背景
- 巨大编号（Anton / Noto Serif SC）+ 杂志感排版
- 数据卡片高密度、不对称网格
- 5 色系编码：瀑布蓝 / 敏捷橙 / AI 青 / 成功绿 / 风险红

### AI 决策的呈现（重点）
**不画拟人化外貌**（不画 AI 大脑 / AI 人形 / AI 头像）。

AI 决策呈现为：
- **决策管道图**（DFD 风格）：数据 → 规则/模型 → 候选 → 证据 → 人工
- **决策卡**：触发 / 建议 / 证据 / 置信度 / 人工确认 5 字段
- **决策日志表**：行 = 决策 ID，列 = 阶段 / 触发 / 建议 / 置信 / 处置 / 备注
- **图标**：⬢ 芯片（六边形），不是 AI 拟人化图标

### 字体
- 中文标题：Noto Serif SC（重量感、区别于普通黑体）
- 英文标题：Anton（condensed industrial）
- 中文正文：Noto Sans SC
- 英文正文：IBM Plex Sans
- 数字：JetBrains Mono

> 字体通过 Google Fonts CDN 加载，断网时优雅 fallback 到系统字体（PingFang SC / Microsoft YaHei）。

## 七、数据来源

所有内容均来自：

> `项目管理生命周期流程表_无人机智能管控平台(1).xlsx`

包含 3 个工作表：
1. `生命周期流程表` —— 5 阶段 10 节点
2. `敏捷管理方式` —— 6 迭代 + 对比矩阵
3. `人员责任表` —— 10×6 RACI 矩阵

**AI 决策点**（19 个）为基于原表内容的工程化扩展，每个决策点都标注了：
- 触发条件
- AI 建议内容
- 证据来源
- 置信度（人工估值）
- 人工确认责任方

## 八、扩展指引

`index.html` 中所有内容数据集中在 `<script id="app-data" type="application/json">` 内，可直接编辑后刷新查看效果。结构清晰：

```jsonc
{
  "phases": [...],        // 5 阶段 10 节点
  "iterations": [...],    // 6 迭代
  "aiDecisions": [...],   // 19 决策点
  "raci": [...],          // 10×6 矩阵
  "metrics": [...],       // 看板指标
  "risks": [...],         // 风险预警
  "retrack": [...]        // 复盘清单
}
```

要新增/修改：
1. 编辑 JSON 数据
2. 刷新浏览器即可看到新内容
3. 无需重新构建
