# iWork 朋友圈文案集合

## 发圈节奏建议

**第一天**：发布群海报 + 文字招募
**第二天**：再发一条补充说明
**第三天**：如果有朋友评论/私信，回复并邀请

---

## Day 1 主文案（配海报）

### 版本A（简洁版）

```
在昆明做[AI/跨境/文创]的伙伴们在哪里？🙋

建了一个本地行业交流群，
目的很简单：让昆明同行的人能互相认识、资源共享。

📌 群里有啥：
• 每日行业资讯分享
• 每周话题讨论
• 每月线下聚会

🔗 有意的朋友，评论区扣1或私信我，邀请你进群～
```

### 版本B（个人故事版）

```
最近在琢磨一件事：

昆明做[AI/跨境/文创]的人，其实挺多的，
但大家好像都是"孤岛"——
做AI的找不到技术合伙人，做跨境的单打独斗，做设计的缺项目资源。

所以我建了个本地小群，
想让同领域的人能互相认识、互通有无。

不搞大群，先精后广。
有想法的朋友，欢迎来聊。

评论区扣"1"，我拉你进群 👇
```

### 版本C（直接版）

```
🧡 昆明本地[AI/跨境/文创]交流群

不做广撒网，只服务真正需要的人。

进群方式：私信我或评论区扣1

---
```

## Day 2 补充文案（可选）

### 如果第一天效果一般，发这个

```
昨天建了群，感谢各位响应！

再说下这个群的定位：
• 不收钱，纯公益
• 不打广告，只交流
• 先做小做精，以后的事以后说

想进群的朋友依然可以私信我或评论～
```

### 如果第一天效果不错，发这个

```
没想到响应还挺积极的🙌

再说几点：
1. 三个群是分开的，根据你做的领域选一个进
2. 进群改群昵称，格式：昵称-方向
3. 群里会定期组织线下活动，欢迎面基

还没进群的朋友，抓紧上船～
```

## 发圈注意事项

1. **时间段**：早上8-9点、中午12-13点、晚上20-22点
2. **配图**：一定要带群海报图片
3. **互动**：有人评论一定要回复
4. **坚持**：连续发3天效果最好

---

## 评论区回复模板

有人评论"1"或"想进"时，这样回复：

```
太好了！我拉你进群～
对了，你主要是做[AI/跨境/文创]哪个方向的？我帮你拉对应的群
```

---

## 风险提示

发朋友圈可能会遇到：
- 没人评论 → 私聊几个熟的朋友直接拉
- 被屏蔽 → 换个时间再发一条
- 被删除 → 正常现象，继续运营就好

别想太多，先发出去再说！
