## 1. 概述

### 1.1 文档目的

本文档是《国产工业物联网平台设计方案》中**鸿蒙物联网关（软网关）**部分的细化实施文档，聚焦于协议转发和设备接入的软网关能力。

### 1.2 定位与职责

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           鸿蒙物联网关定位                              │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                      │
│   ┌───────────────┐         ┌───────────────────┐        ┌──────────┐ │
│   │   工业设备     │         │   鸿蒙软网关       │        │  平台侧  │ │
│   │  (传感器/执行器)│◄──────►│  (协议转发/转换)   │◄──────►│  IoTDA   │ │
│   └───────────────┘         └───────────────────┘        └──────────┘ │
│                                                                      │
│   接入能力：                    核心能力：                  上行：    │
│   - MQTT客户端                 - 协议转换                  - MQTT     │
│   - Modbus主站                 - 数据转发                    │
│   - HTTP客户端                 - 设备管理                  下行：    │
│   - CoAP客户端                 - 本地缓存                  - 命令下发 │
│                                 - 断网续传                  │
└─────────────────────────────────────────────────────────────────────────────┘
```

| 职责 | 说明 |
|------|------|
| **协议转换** | 将MQTT/Modbus/Http等协议转换为平台统一协议 |
| **设备接入** | 作为平台南向代理，接入各类IoT设备 |
| **数据转发** | 将设备数据上报平台，平台命令下发设备 |
| **本地缓存** | 断网时本地缓存数据，恢复后补发 |
| **设备管理** | 设备注册、认证、心跳、在线状态管理 |

### 1.3 核心设计目标

| 目标 | 说明 |
|------|------|
| **全协议覆盖** | 支持MQTT/CoAP/LwM2M/Modbus/Http/TCP/UDP |
| **碰一碰配网** | 基于鸿蒙分布式能力，快速发现和配置设备 |
| **断网自治** | 72小时断网自主运行，数据不丢失 |
| **低资源消耗** | 支持在Hi3861等轻量级模组上运行 |
| **安全传输** | TLS/DTLS加密，双向认证 |

### 3.3 数据缓存模块

#### 3.3.1 缓存策略

| 缓存类型 | 触发条件 | 缓存时长 | 同步策略 |
|----------|----------|----------|----------|
| **实时数据** | 正常连接 | 0 | 实时同步 |
| **告警数据** | 告警触发 | 72h | 优先同步 |
| **历史数据** | 断网 | 72h | 恢复后补传 |
| **命令响应** | 命令下发 | 24h | 优先同步 |

#### 3.3.2 缓存数据结构

```c
// 缓存数据条目结构
struct cache_entry {
    uint8_t type;           // 数据类型 (DATA/ALARM/COMMAND)
    uint64_t timestamp;     // 时间戳
    uint16_t data_len;      // 数据长度
    uint8_t qos;            // MQTT QoS
    uint8_t retry_count;     // 重试次数
    uint8_t status;          // 状态 (PENDING/SENT/CONFIRMED)
    uint8_t data[];          // 数据内容
};

// 缓存队列管理
struct cache_queue {
    uint32_t max_size;      // 最大缓存条目数
    uint32_t current_size;   // 当前条目数
    uint32_t write_index;    // 写索引
    uint32_t read_index;     // 读索引
    struct cache_entry entries[];
};
```

### 8.3 故障恢复

| 故障 | 症状 | 处理方法 |
|------|------|----------|
| **MQTT断开** | 设备离线 | 自动重连，启用本地缓存 |
| **Modbus设备无响应** | 数据停滞 | 标记设备异常，尝试重连 |
| **磁盘空间不足** | 写入失败 | 清理旧日志，删除缓存 |
| **内存泄漏** | 内存持续增长 | 重启网关服务 |
| **程序崩溃** | 服务不可用 | 自动重启，生成core文件 |
