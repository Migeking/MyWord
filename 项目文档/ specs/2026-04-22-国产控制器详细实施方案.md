## 1. 概述

### 1.1 文档目的

本文档是《国产工业物联网平台设计方案》中**国产控制器**部分的细化实施文档，详细描述国产控制器的选型、软硬件架构、通信协议、数据模型、部署步骤和验收标准。

### 1.2 范围

| 项目 | 说明 |
|------|------|
| **控制器类型** | 国产工业PLC / 鸿蒙软网关 / 边缘计算控制器 |
| **通信协议** | 鸿蒙设备协议、MQTT、Modbus TCP/RTU |
| **部署位置** | 工厂车间设备层 |
| **集成对象** | 平台接入层（华为IoTDA / 工业协议网关） |

### 1.3 目标

- 建立统一的国产控制器接入标准
- 实现控制器即插即用（碰一碰配网）
- 支持本地边缘计算和断网自治
- 与平台侧无缝对接

## 2. 控制器选型

### 2.1 候选产品

| 厂商 | 产品型号 | CPU | 内存 | 存储 | 操作系统 | 通信接口 | 适用场景 |
|------|---------|-----|------|------|----------|----------|----------|
| **中移物联网** | OneOS边缘控制器 | ARM Cortex-A | 512MB+ | 4GB+ | OneOS RTOS | Ethernet/串口/CAN | 通用工业控制 |
| **华为** | Hi3861模块 | RISC-V | 288KB | 2MB | HarmonyOS LiteOS | WiFi/Ethernet | 轻量级采集 |
| **华为** | Hi3518E方案 | ARM9 | 128MB | 512MB | OpenHarmony | Ethernet | 网关/小型控制 |
| **汇川技术** | AM系列PLC | ARM Cortex-A | 256MB | 512MB | 汇川PLC OS | Ethernet/串口 | 运动控制 |
| **和利时** | LK系列PLC | ARM | 128MB | 256MB | Linux | Ethernet/串口 | 过程控制 |
| **信捷电气** | XC系列PLC | ARM | 64MB | 128MB | 汇编/RTOS | Ethernet/串口 | 小型自动化 |

### 2.2 推荐方案

**推荐选择：中移OneOS边缘控制器 + 鸿蒙Hi3861模块组合**

| 组合 | 控制器 | 定位 |
|------|--------|------|
| **主控单元** | 中移OneOS边缘控制器 | 复杂控制逻辑、边缘计算、数据聚合 |
| **采集单元** | 鸿蒙Hi3861模块 | 传感器数据采集、协议转换 |

**选择理由**：
- OneOS是国资委背书的国产实时操作系统
- 支持主流工业协议（Modbus、OPC UA客户端）
- 鸿蒙生态加持，支持碰一碰配网
- 华为/中移动双生态保障供应链安全

### 4.2 鸿蒙设备协议详细规范

#### 4.2.1 消息格式

```json
{
  "protocol_version": "1.0",
  "message_type": "DATA_REPORT",  // DATA_REPORT / COMMAND / EVENT / OTA
  "device_id": "CN_DEVICE_001",
  "timestamp": 1745328000000,
  "payload": {
    "data_points": [
      {
        "tag": "temperature",
        "value": 25.6,
        "quality": "GOOD",
        "timestamp": 1745327999000
      },
      {
        "tag": "pressure",
        "value": 101.325,
        "quality": "GOOD",
        "timestamp": 1745327999000
      }
    ],
    "properties": {
      "status": "RUNNING",
      "mode": "AUTO"
    }
  },
  "signature": "BASE64_SIGNATURE"
}
```

#### 4.2.2 消息类型说明

| 消息类型 | 说明 | 方向 |
|----------|------|------|
| **DATA_REPORT** | 设备数据上报 | 控制器 → 平台 |
| **COMMAND** | 平台命令下发 | 平台 → 控制器 |
| **EVENT** | 设备事件上报 | 控制器 → 平台 |
| **OTA** | 固件升级指令 | 平台 → 控制器 |

### 4.3 MQTT主题设计

| 主题 | 说明 | QoS |
|------|------|-----|
| `iot/{org_id}/{device_id}/report` | 设备数据上报 | 1 |
| `iot/{org_id}/{device_id}/command` | 平台命令下发 | 2 |
| `iot/{org_id}/{device_id}/event` | 设备事件上报 | 1 |
| `iot/{org_id}/{device_id}/ota` | OTA升级指令 | 2 |
| `iot/{org_id}/{device_id}/shadow` | 设备影子同步 | 0 |

### 6.3 阶段2：软件部署

#### 步骤2.1：烧录固件

| 工具 | 说明 |
|------|------|
| OneOS Studio | OneOS官方IDE，用于固件烧录 |
| HiBurn | Hi3861烧录工具 |

**烧录步骤（OneOS边缘控制器）**：
1. 使用USB线连接控制器与PC
2. 打开OneOS Studio
3. 选择固件包 `oneos_ec100_v2.0.1.bin`
4. 选择连接端口（如COM3）
5. 点击"烧录"按钮
6. 等待烧录完成（约3分钟）
7. 验证烧录版本号

**烧录步骤（Hi3861模块）**：
1. 使用HiBurn工具加载固件
2. 选择串口波特率 115200
3. 点击"烧录"并等待完成

#### 步骤2.2：初始配置

通过串口登录控制器进行初始配置：

```bash
# 登录控制器
> sh

# 查看系统信息
# cat /proc/cpuinfo
# cat /proc/meminfo

# 配置网络
$ netadm init eth0
$ netadm set ip 192.168.1.100
$ netadm set mask 255.255.255.0
$ netadm set gw 192.168.1.1

# 配置平台连接
$ vi /etc/iotda.conf
```

**iotda.conf 配置文件**：
```ini
[platform]
server = platform.iotservice.cn
port = 1883
org_id = your_org_id
device_id = CN_DEVICE_001
device_secret = your_device_secret

[network]
network_type = eth0
dhcp = false

[edge]
enable = true
local_storage = true
offline_cache_hours = 72
```

#### 步骤2.3：配置数据采集

```bash
# 创建Modbus采集任务
$ modbus_config add --name temperature_sensor
$ modbus_config set --slave-id 1 --function-code 3 --address 0 --count 2

# 配置数据点映射
$ tag_mapping add --tag AI_001 --modbus-slave 1 --register 0 --type float
$ tag_mapping add --tag AI_002 --modbus-slave 1 --register 2 --type float

# 启动采集
$采集任务 start temperature_sensor
```

#### 步骤2.4：配置边缘规则

```bash
# 创建边缘规则：温度>60℃触发告警
$ edge_rule create --name temp_alarm
$ edge_rule set --condition "AI_001 > 60" --action "report_alarm"
$ edge_rule set --condition "AI_001 > 80" --action "emergency_stop"
$ edge_rule enable
```

### 8.2 故障处理

| 故障现象 | 可能原因 | 处理方法 |
|----------|----------|----------|
| **设备不在线** | 网络不通/服务未启动 | 检查网络、重启服务 |
| **数据不上报** | 采集任务异常/MQTT断开 | 重启采集任务、重连MQTT |
| **命令不响应** | 命令队列满/网络延迟 | 清空队列、检查网络 |
| **本地存储满** | 缓存数据未清理 | 清理过期数据、同步到平台 |
