## 1. 概述

### 1.1 文档目的

本文档是《国产工业物联网平台设计方案》中**工业协议网关**部分的细化实施文档，详细描述工业协议网关的软硬件架构、协议支持、数据模型、部署步骤和运维管理。

## 3. 协议支持矩阵

### 3.1 协议支持总览

| 协议类型 | 协议名称 | 厂商/设备 | 支持情况 | 实现方式 |
|----------|----------|-----------|----------|----------|
| **OPC UA** | OPC UA Client | 西门子/ABB/施耐德/主流厂商 | 已支持 | 华为IGT |
| **西门子** | S7-300/400/1200/1500 | 西门子PLC | 已支持 | 华为IGT |
| **三菱** | MC Protocol (QnA3E) | 三菱PLC Q/L/FX系列 | 已支持 | 华为IGT |
| **欧姆龙** | Fins/TCP | 欧姆龙PLC CJ/CP/CS系列 | 已支持 | 华为IGT |
| **Modbus** | Modbus TCP/RTU/ASCII | 通用传感器/变频器/国产PLC | 已支持 | 开源libmodbus |
| **华为** | Huawei Industrial Protocol | 华为工控设备 | 已支持 | 华为私有协议 |
| **和利时** | Hollysys Protocol | 和利时PLC | 计划支持 | 定制开发 |
| **汇川** | Inovance Protocol | 汇川PLC/变频器 | 计划支持 | 定制开发 |
| **台达** | Delta Protocol | 台达PLC/变频器 | 计划支持 | 定制开发 |

| 功能 | 说明 |

| **S7协议** | 支持S7-300/400/1200/1500，支持read/write/notify |

### 4.1 协议驱动框架

#### 4.1.1 统一驱动接口

```c
// 统一协议驱动接口
typedef struct protocol_driver {
    const char* name;                    // 驱动名称
    const char* version;                 // 驱动版本

    // 连接管理
    int (*connect)(void* ctx, const char* remote_ip, int port, void* params);
    int (*disconnect)(void* ctx);
    int (*is_connected)(void* ctx);

    // 数据读写
    int (*read)(void* ctx, const char* tag, void* value, int* quality);
    int (*write)(void* ctx, const char* tag, const void* value, int quality);
    int (*read_batch)(void* ctx, const char** tags, void** values, int* qualities, int count);

    // 订阅（可选）
    int (*subscribe)(void* ctx, const char** tags, int count, callback_fn cb);
    int (*unsubscribe)(void* ctx, const char** tags, int count);

    // 诊断
    int (*get_status)(void* ctx, driver_status_t* status);
    int (*diagnose)(void* ctx, diagnose_result_t* result);
} protocol_driver_t;
```

#### 4.1.2 驱动注册机制

// 驱动注册表

int protocol_driver_register(const char* protocol_name, protocol_driver_t* driver);

// 获取驱动

### 4.3 协议转换模块

#### 4.3.1 统一数据模型

```c
// 统一数据点结构
typedef struct data_point {
    char tag[64];                // 数据点标识
    uint64_t timestamp;          // 时间戳(ms)
    union {
        int8_t b;               // 布尔值
        int16_t i16;             // 16位整数
        int32_t i32;             // 32位整数
        float f;                 // 浮点数
        double d;                // 双精度浮点数
        char s[256];             // 字符串
    } value;
    int quality;                 // 数据质量 (0=GOOD, 1=UNCERTAIN, 2=BAD)
} data_point_t;

// 数据质量定义
#define QUALITY_GOOD      0xC0
#define QUALITY_UNCERTAIN 0x40
#define QUALITY_BAD       0x00
```

### 4.4 缓存模块

#### 4.4.1 缓存策略

| 缓存类型 | 触发条件 | 缓存时长 | 同步策略 |
|----------|----------|----------|----------|
| **实时数据** | 正常连接 | 0 | 实时同步 |
| **历史数据** | 断网 | 72h | 恢复后补传 |
| **告警数据** | 告警触发 | 72h | 优先同步 |
| **批次数据** | 断网 | 168h | 按批次同步 |

#### 4.4.2 缓存数据结构

```c
// 缓存条目
typedef struct cache_entry {
    uint32_t id;                 // 序列号
    uint8_t type;               // 数据类型
    uint64_t timestamp;         // 时间戳
    uint8_t priority;           // 优先级 (0=Highest)
    uint16_t data_len;          // 数据长度
    uint8_t status;              // 状态
    uint8_t retry;               // 重试次数
    uint8_t data[];              // 数据
} cache_entry_t;

// 缓存状态
typedef struct cache_status {
    uint32_t total_count;       // 总条目数
    uint32_t pending_count;      // 待发送数
    uint32_t sent_count;         // 已发送数
    uint64_t cache_size;         // 缓存大小
    uint64_t max_size;           // 最大缓存
    time_t oldest_time;          // 最老时间
    time_t newest_time;          // 最新时间
} cache_status_t;
```

### 5.2 南向接口（对工业设备）

#### 5.2.1 S7协议接口

| 功能 | 说明 |
|------|------|
| **连接** | ISO-over-TCP (RFC1006), HSK交换, 读写请求 |
| **读** | DB/M/E/PA/PI区，支持bit/byte/word/dword |
| **写** | DB/M/E/PA/PI区，支持bit/byte/word/dword |
| **订阅** | 变量订阅，变化通知 |

**S7变量地址格式**：
```
DB1.DBD0     - DB块1, DWord偏移0 (float)
DB1.DBW2     - DB块1, Word偏移2 (int16)
M10.0        - 标记区，位10.0
PE1.0        - 过程输入，位1.0
PA1.0        - 过程输出，位1.0
```

#### 5.2.2 MC协议接口

| 功能 | 说明 |
|------|------|
| **连接** | TCP连接，三菱QnA兼容3E帧格式 |
| **读** | 位/字/双字，支持X/Y/M/LC/L/D/R/ZR |
| **写** | 位/字/双字，支持X/Y/M/LC/L/D/R/ZR |
| **批量** | 批量读写 |

**MC协议变量地址格式**：
```
D100         - 数据寄存器D100 (字)
D100.D       - 数据寄存器D100 (双字)
M100         - 辅助继电器M100 (位)
X100         - 输入继电器X100 (位)
Y100         - 输出继电器Y100 (位)
W$00A0       - 链接继电器W00A0 (字)
```

#### 5.2.3 Modbus接口

| 功能 | 说明 |
|------|------|
| **连接** | TCP/RTU，支持多个从站 |
| **读** | 线圈(0x01)/离散输入(0x02)/保持寄存器(0x03)/输入寄存器(0x04) |
| **写** | 单线圈(0x05)/单寄存器(0x06)/多线圈(0x0F)/多寄存器(0x10) |
| **批量** | 批量读写 |

## 8. 诊断与运维

### 8.1 协议层诊断

| 诊断项 | 说明 | 触发条件 |
|--------|------|----------|
| **连接状态** | TCP连接是否建立 | 实时监控 |
| **通信质量** | 成功率/时延/超时 | 每次通信 |
| **协议错误** | 错误码解析 | 通信错误时 |
| **数据质量** | 数据点quality状态 | 每次采集 |

### 8.2 诊断命令

```bash
# 查看所有连接状态
$ curl http://localhost:8080/api/v1/connections

# 诊断指定连接

# 查看标签状态
$ curl http://localhost:8080/api/v1/tags

# 查看网关状态
$ curl http://localhost:8080/api/v1/gateway/status

# 查看缓存状态
$ curl http://localhost:8080/api/v1/cache/status

# 清除缓存
$ curl -X POST http://localhost:8080/api/v1/cache/clear
```

### 8.4 故障处理

| 故障 | 可能原因 | 处理方法 |
|------|----------|----------|
| **连接不上PLC** | IP错误/防火墙/PLC未上电 | 检查网络/电源/配置 |
| **数据为0** | 地址错误/数据类型错误 | 检查tag配置/字节序 |
| **数据跳变** | 信号干扰/接线问题 | 检查硬件/添加滤波器 |
| **采集超时** | 设备负载高/网络繁忙 | 增加超时/减少采集频率 |
| **内存持续增长** | 缓存泄漏 | 重启网关/检查版本 |
