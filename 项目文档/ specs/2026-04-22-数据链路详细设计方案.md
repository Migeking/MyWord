### 1.2 数据链路分段

| 链路段 | 方向 | 描述 | 关键技术 |
|--------|------|------|----------|
| **采集链路** | 设备→边缘 | 数据从设备采集到边缘节点 | 工业协议/Modbus/MQTT |
| **传输链路** | 边缘→平台 | 数据从边缘传输到云端 | RocketMQ/TLS |
| **存储链路** | 平台→存储 | 数据写入存储系统 | TDengine/openGauss |
| **消费链路** | 存储→应用 | 应用从存储读取数据 | REST/gRPC/WebSocket |
| **命令链路** | 应用→设备 | 命令从应用下发到设备 | MQTT Subscribe/发布 |

### 2.2 各链路数据格式

| 链路节点 | 数据格式 | 示例 |
|----------|----------|------|
| **PLC寄存器** | S7 S7-any类型 | DB1.DBD0 (32位浮点) |
| **Modbus寄存器** | 16位无符号整数 | 40001 (保持寄存器) |
| **MC寄存器** | 三菱Q系列格式 | D100 (字) |
| **软网关输出** | JSON | `{"tag":"temp","value":25.6}` |
| **MQTT消息体** | JSON | `{"device_id":"xxx","data_points":[...]}` |
| **本地TDengine** | 时序数据行 | `1735328000,device_001,25.6` |

### 2.3 采集链路协议支持

| 设备类型 | 协议 | 采集频率 | 数据量/秒 |
|----------|------|----------|-----------|
| PLC (西门子) | S7 | 1-10Hz | 100-1000 bytes |
| PLC (三菱) | MC | 1-10Hz | 100-1000 bytes |
| PLC (欧姆龙) | Fins | 1-10Hz | 100-1000 bytes |
| 传感器 (温度) | Modbus | 1Hz | 10-50 bytes |
| 传感器 (振动) | Modbus | 10-100Hz | 50-200 bytes |
| 工业相机 | HTTP/RTSP | 10-30fps | 1-10 MB/帧 |

### 3.2 RocketMQ消息配置

| 配置项 | 值 | 说明 |
|--------|-----|------|
| **Broker地址** | rocketmq:9876 | RocketMQ服务地址 |
| **Topic** | iot-data-raw | 原始数据Topic |
| **Group** | gw-group | 消费者组 |
| **QoS** | 1 | 至少一次投递 |
| **消息大小** | < 64KB | 单条消息限制 |
| **保留时间** | 7天 | 消息保留周期 |
| **分区数** | 6 | 并行度 |

**消息格式**：
```json
{
  "msg_id": "uuid-xxx",
  "gateway_id": "GW_001",
  "timestamp": 1745328000000,
  "sequence": 1001,
  "payload": {
    "device_id": "PLC_Siemens_001",
    "protocol": "S7",
    "data_points": [
      {
        "tag": "temperature",
        "value": 25.6,
        "quality": "GOOD",
        "timestamp": 1745327999000
      }
    ]
  },
  "metadata": {
    "source": "edge-node-001",
    "sync_status": "pending"
  }
}
```

### 3.3 数据同步策略

| 数据类型 | 同步策略 | 时效性 | 带宽占用 |
|----------|----------|--------|----------|
| **实时告警** | 实时同步 | < 1s | 低 |
| **工艺参数** | 实时同步 | < 1s | 中 |
| **设备状态** | 批量同步 (5s间隔) | < 10s | 低 |
| **统计数据** | 批量同步 (60s间隔) | < 2min | 中 |
| **历史数据** | 断网恢复后同步 | 恢复后 | 高 |

### 5.3 查询示例

**时序数据查询**：
```sql
-- 查询设备温度趋势（最近1小时）
SELECT _TS, temperature 
FROM sensor_data 
WHERE device_id = 'device_001' 
  AND _TS >= NOW() - 1h 
ORDER BY _TS;
```

**聚合查询**：
```sql
-- 按产线统计每小时产量
SELECT _TS, SUM(quantity) as output
FROM production_data
WHERE line_id = 'L001'
  AND _TS >= NOW() - 24h
GROUP BY TUMBING(1h)
ORDER BY _TS;
```

## 8. 数据质量保障

### 8.1 数据质量检查点

| 检查点 | 位置 | 检查内容 | 异常处理 |
|--------|------|----------|----------|
| **格式校验** | 协议网关 | JSON格式、字段完整性 | 丢弃并告警 |
| **范围校验** | 边缘节点 | 值是否在合理范围 | 标记质量为BAD |
| **连续性检查** | 边缘节点 | 数据是否连续 | 补齐或告警 |
| **一致性检查** | 服务层 | 多数据源一致性 | 告警通知 |
| **及时性检查** | 服务层 | 数据是否及时 | 超时告警 |

### 8.2 数据链路监控指标

| 指标 | 描述 | 告警阈值 |
|------|------|----------|
| **数据完整率** | 实际数据/理论数据 | < 99% |
| **消息时延** | 端到端延迟 | P99 > 1s |
| **消息积压** | RocketMQ积压量 | > 10000 |
| **存储延迟** | TDengine写入延迟 | > 100ms |
| **边缘离线时长** | 边缘节点离线时间 | > 1h |
