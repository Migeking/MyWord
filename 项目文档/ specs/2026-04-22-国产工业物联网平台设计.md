# 国产工业物联网平台设计方案

**项目**：国产工业物联网平台（单一工厂/车间产线监控）
**版本**：v1.0
**日期**：2026-04-22
**状态**：草稿

---

## 1. 项目概述

### 1.1 背景与目标

本项目旨在打造一款**全栈国产化**的工业物联网平台，面向单一工厂/车间场景，提供产线设备监控、数据存储、边缘计算和工业App的全栈能力。

平台基于**鸿蒙生态**构建，充分发挥国产操作系统和中间件的优势，实现工业设备接入、数据采集、边缘计算和应用的完全国产化。

### 1.2 核心需求

| 需求类型 | 具体描述 |
|---------|---------|
| **场景定位** | 单一工厂产线监控 |
| **设备接入** | 标准工业协议 + 私有协议 + 国产设备，支持鸿蒙生态 |
| **数据能力** | 实时监控大屏、数据历史存储、边缘计算、工业App |
| **技术路线** | 全栈国产化（操作系统、中间件、数据库、应用框架） |
| **集成现状** | IT系统（MES/ERP）和OT系统（PLC/DCS）均已存在 |

### 1.3 设计约束

- 必须使用国产化组件，禁止使用国外商业产品
- 支持与现有SCADA/DCS、MES/ERP系统对接
- 支持断网续传和边缘自治能力
- 满足工业场景的实时性和可靠性要求

## 8. 下一步计划

本设计方案经审批后，建议按以下顺序实施：

1. **第一阶段：基础设施搭建**
   - 部署openEuler服务器
   - 搭建KubeEdge集群
   - 部署IoTDA接入服务

2. **第二阶段：设备接入**
   - 部署工业协议网关
   - 对接现有PLC/SCADA
   - 验证设备通信

3. **第三阶段：数据层建设**
   - 部署TDengine、openGauss、RocketMQ
   - 构建数据采集和存储流程

4. **第四阶段：应用开发**
   - 开发鸿蒙原生App
   - 部署工业App服务

5. **第五阶段：边缘计算**
   - 部署边缘计算节点
   - 实现边缘规则引擎
