# AI 漫剧生成低成本方案调研报告

> 调研时间：2026-08-02　|　背景：以自有小说剧本制作漫剧，投放到红果短剧等平台
> 关注点：千问万相（Wan）模型 vs C-Dance 的成本对比，以及更省钱的替代路线

---

## 一、市场现状（关键结论）

1. **红果已推出独立的「红果免费漫剧」品牌**（原「咸柠免费短剧」升级），漫剧在字节系是明确的扶持品类。爱奇艺也专门开设了「漫剧频道」（含 AI剧、AI动画、AI动态漫、沙雕漫等类型）。
2. **AI 漫剧在 2026 年已高度集中在字节系闭环**：Seedance 系列占短剧 Token 消耗的 80%+，可灵紧随其后，形成"双寡头"格局。
3. **爆款案例**：AI 漫剧《精神小妹也要修机甲吗》播放量破 2 亿（出品方：畅语剧场）。
4. **政策收紧**：2026 年 6 月起微短剧（含 AI 漫剧）全面执行"先备案、后上线"，分类分层管理。AI 内容生产与分发需符合平台备案要求。

## 三、低成本方案分层（由省到贵）

### 方案 A：AI 动态漫流水线（最省钱，强烈推荐起步）≈ 0 元/集

原理：静态漫画分镜 + 镜头动效 + 配音 = 动态漫。这是红果主流的"AI 动态漫"形态，平台也重点扶持。

| 环节 | 低成本工具 | 成本 |
|---|---|---|
| 剧本→分镜/台词 | 豆包、DeepSeek、千问（免费） | 0 |
| 漫画分镜图（角色一致性） | 即梦 / 豆包 / 可灵 免费额度；或本地 SD / FLUX | 0 |
| 镜头动效（缩放/平移/粒子/转场/口型） | 剪映专业版、CapCut（免费）；数字人可试试剪映"数字人" | 0 |
| 配音 | Edge TTS（免费）、ChatTTS（开源免费）、阿里云 CosyVoice（免费额度）、GPT-SoVITS（免费克隆音色） | 0 |
| BGM/音效 | 剪映曲库（商用授权） | 0 |
| 合成导出 | 剪映/CapCut 一键出片 | 0 |

- **单集 2~3 分钟制作时间约 2~4 小时**，熟练后可以批量。
- 你的项目里已经有「HTML 动画 → Playwright 录屏 → 成片」的成熟流水线（`scripts/capture_*.py`），可以升级成"高级动态漫"（手绘风 HTML/GSAP 动画 + TTS + 录屏），风格更独特、成本依然≈0。

### 方案 B：视频生成模型路线（C-Dance / 即梦 / 可灵 / 万相 / H3）

- 适合已经验证流量、需要"动态感更强"的画面时再上。
- **结论：C-Dance 你说贵是对的**——它本质是 Seedance 2.0 的聚合站，单条约 1 块钱（4~5s），一集 40 元左右。除非：① 年付 Studio（$899.99，压到 ~14 元/集，需要年产 20000 条的量）；② 它的多模型聚合（Wan/Veo/Kling）当"保险"用。
- **最省的视频生成路线其实是阿里云百炼的万相 API**：wan2.7 是当前推荐款（有声、多镜头、15s），单价在主流模型里最便宜，还能拿新用户免费额度。会写代码（你有这个能力）就走 API 批量。
- 如果只是尝鲜：豆包（Seedance 免费额度）、可灵每日 66 灵感值、C-Dance 注册送积分，先白嫖验证效果。

### 方案 C：本地开源路线（0 素材费，需算力）

- 开源模型：Wan 2.2/2.5（阿里）、HunyuanVideo（腾讯）、CogVideoX（智谱）、LTX-Video、AnimateDiff+漫画图、LivePortrait（对口型）。
- 需要 4090 级别显卡或租云 GPU（AutoDL 等，约 2~8 元/小时）。
- 优点：角色一致性可自控（LoRA 训练主角）、无限量；缺点：部署门槛高、出片速度慢。
- 适合：已经确定爆款方向后的大批量生产阶段。

### 方案 D：一站式平台（免搭建）

- **漫剧工场**（manjugongchang.com）：剧本市场 / 小说 IP 授权 / 制作团队对接 / 发行合作（红果、快手星芒、ChillShorts 等），6800+ 创作者。适合找外包或卖剧本/买授权。
- **OiiOii.ai**：AI 动画 Agent，短漫剧工业化，效率提升 5 倍、成本降 3 倍，支持"一键出海"（1 天跑出 5 国版本）。
- **腾讯智影**：动态漫画生成功能，腾讯系分发。
- **客易云 Global AI OPC 漫剧平台**：AI 漫剧创作+发行。

## 四、平台侧：怎么上红果、怎么赚钱

1. **官方通道**：抖音集团官方短剧版权中心（一站式服务平台），漫剧可同步分发至**抖音主站 + 红果短剧**等多端流量池；作品上线后按分账协议结算，可查分账明细。漫剧工场等第三方也有红果发行合作通道。
2. **收益结构（近年变化）**：
   - 红果 / 河马剧场 此前是"基础保底 + 流水分成"双补贴，重点扶持 AI 动态漫和 AI 仿真人剧集；
   - **⚠️ 2025 年底以来红果对 AI 短剧的保底政策有所调降**（分账金额缩水），行业从"补贴驱动"转向"内容质量驱动"；
   - 快手侧激励更高：星芒创想计划 / 全民 AI 制作人计划，单部优质 AI 漫剧最高 **50 万现金 + 1 亿流量奖励**（可同时布局快手）。
3. **合规三件事**：① 微短剧先备案后上线（含 AI 漫剧）；② 改编网文需取得 IP 授权（漫剧工场有小说 IP 授权市场，也可直接联系番茄/阅文等版权方）；③ AI 生成内容按平台要求标注。

## 五、给你的落地建议（按你的情况）

你的画像：有小说剧本 + 会写代码 + 已有 HTML 动画转视频流水线 + 想低成本验证。

**第一阶段（验证，预算 ≈ 0）**
1. 挑 1 部剧本，用 LLM 拆成 8~12 集每集 2~3 分钟的分镜+台词表；
2. 用方案 A 动态漫流程出 **2~3 集样片**（即梦出图 + 剪映动效 + Edge TTS/CosyVoice 配音）；
3. 同步用你现有的 HTML+Playwright 流水线做一集"风格化动态漫"对比观感；
4. 样片走抖音短剧版权中心备案上架，测数据。

**第二阶段（放量，预算几百元）**
5. 数据验证 OK 后：小批量用 C-Dance Starter 年付（$99.99 ≈ 720 元，750 条 ≈ 16 集 3 分钟）或直接阿里云百炼万相 API（单价更低、按量付费、新用户有免费额度）；
6. 配音批量用 CosyVoice / GPT-SoVITS 固定音色（主角音色一致性）。

**第三阶段（规模化）**
7. 若单部剧跑出稳定分账：上本地 Wan 2.x + LoRA 角色库（租 GPU），单集素材成本压到几元，或签漫剧工场的承制/发行合作放大产能。
