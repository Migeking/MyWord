⚠️ 已知问题：语言代码映射

npx hyperframes tts 的 --lang zh 参数无法直接使用，因为底层 eSpeak 使用 cmn（而非 zh）作为普通话代码。HyperFrames CLI 验证了 --lang 参数白名单（仅允许 en-us, en-gb, es, fr-fr, hi, it, pt-br, ja, zh），导致中文无法通过官方 CLI 生成。

解决方案：编写 tts.py 直接调用 Python kokoro-onnx API，将语言自动映射为 cmn。脚本已包含在项目目录中。

TTS 生成命令（绕过语言限制）

python tts.py "待配音的文字内容" -o output.wav --voice zf_xiaobei --speed 1.0 --lang cmn

三、技术架构

3.1 核心组件

组件 说明
HTML Composition 基于 HTML + CSS + GSAP 动画的视频描述
HyperFrames CLI 命令行工具：lint, preview, render, publish
GSAP 动画引擎（需加载 gsap.min.js）
Chrome Headless 无头浏览器渲染引擎

3.2 项目结构

test-video/
├── index.html          # 主视频组合（必须）
├── compositions/      # 子组合目录
├── assets/           # 资源文件
├── hyperframes.json  # 项目配置
├── meta.json         # 元数据
├── package.json      # npm 脚本
└── renders/          # 渲染输出

3.3 HTML 编写规则

必填属性

  • data-composition-id - 组合唯一 ID
  • data-width / data-height - 画布尺寸
  • data-start - 开始时间（秒）
  • data-duration - 持续时间（秒）
  • data-track-index - 轨道索引（控制 z-order）

可见元素

需要动画的元素必须添加 class="clip"，运行时才能管理其可见性生命周期。

GSAP 时间线注册

window.__timelines = window.__timelines || {};
window.__timelines["main"] = gsap.timeline({ paused: true });
// 然后添加动画...

四、与现有工具对比

现有 xhs-animated.html

当前方案
  • 基于纯 HTML + GSAP
  • 手动编辑 HTML
  • 需要 capture 脚本转视频
  • 无模板复用机制
  • 适合单次创作

HyperFrames

推荐方案
  • HTML + GSAP + CLI
  • AI 辅助生成
  • 内置 render 命令
  • 模板批量复制
  • 适合批量生产

关键差异

维度 xhs-animated.html HyperFrames
批量生成 ❌ 需手动复制修改 ✅ 复制 HTML + 改内容
渲染方式 第三方 capture 脚本 内置 hyperframes render
预览方式 浏览器打开 hyperframes preview
AI 集成 ❌ 无 ✅ 技能系统辅助生成
视频质量 依赖 capture 设置 30fps HDR/SDR 可选

5.2 具体整合路径

方案 A：纯 HyperFrames（推荐）

将现有内容转换为 HyperFrames 格式，直接使用 HyperFrames 批量生成。

# 1. 创建小红书风格模板
npx hyperframes init xhs-video --example blank

# 2. 使用 AI 技能生成内容
# "使用 /hyperframes 创建一个 15 秒的小红书封面视频"

# 3. 复制模板生成系列
cp index.html index-video2.html
# 修改标题、图片、文字

# 4. 批量渲染
npx hyperframes render . --output video1.mp4
npx hyperframes render . --composition index-video2.html --output video2.mp4

方案 B：渐进迁移

保留现有 xhs-animated.html，逐步将可复用部分迁移到 HyperFrames。

  • 动画逻辑保持 GSAP，适配 HyperFrames 结构
  • 图片资源通过变量注入
  • 分阶段实现批量生产

5.3 技术要点

要点 说明
分辨率 小红书竖版推荐 1080×1920
字体 使用 Google Fonts，HyperFrames 会自动缓存
图片 避免外部 URL，用 SVG 或本地文件
变量注入 使用 --variables '{"title":"新标题"}' 批量替换

六、结论与建议

HyperFrames 的核心价值

HyperFrames 的本质是模板复用 + CLI 批量化，它不替代创作，而是让创作的生产效率指数级提升。

适合场景

  • 产品宣传视频批量生成（同一模板，不同产品）
  • 小红书系列内容制作（固定风格，快速迭代）
  • 教程/说明视频（同一结构，不同内容）
  • A/B 测试变体生成
